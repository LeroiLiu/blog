## 首先说一下汉化

汉化插件需要用Package Control组件安装，所以首先我们要在Sublime上安装Package Control组件

1. 按Ctrl + ~ 调出console
2. 粘贴下列代码到命令行底部后回车

```text
import urllib.request,os,hashlib;
h = 'df21e130d211cfc94d9b0905775a7c0f' + '1e3d39e33b79698005270310898eea76';
pf = 'Package Control.sublime-package';
ipp = sublime.installed_packages_path();
urllib.request.install_opener( urllib.request.build_opener( urllib.request.ProxyHandler()) );
by = urllib.request.urlopen( 'http://packagecontrol.io/' + pf.replace(' ', '%20')).read();
dh = hashlib.sha256(by).hexdigest();
print('Error validating download (got %s instead of %s), please try manual install' % (dh, h)) if dh != h else open(os.path.join( ipp, pf), 'wb' ).write(by)
```

3. 重启Sublime Text3
4. 如果在 `首选项->浏览插件目录->User` 中看到 package control 这一项，则安装成功。
5. 按Ctrl + Shift + P调出命令面板并输入Install Package回车 ![首先说一下汉化示意图](/blog/images/blog/87264761/local-001.webp)
6. 在弹出的界面输入chinese,选择ChineseLocalization汉化完成

> 后面的插件都是通过`install package`搜索后安装的

### Sublime Text 3常用快捷键

- `Ctrl+D`：选中光标所在的文本；继续操作会选中下一个相同文本。
- `Alt+F3`：选中文本后一次性选择全部相同文本，以便同时编辑。
- `Ctrl+L`：选中整行；继续操作会选择下一行，效果与 `Shift+↓` 相同。
- `Ctrl+Shift+L`：先选中多行，再在每行行尾插入光标，以便同时编辑。
- `Ctrl+Shift+M`：选择括号内的内容；继续操作会选择父级括号。
- `Ctrl+M`：将光标移动到括号开始或结束的位置。
- `Ctrl+Enter`：在下一行插入新行。
- `Ctrl+Shift+Enter`：在上一行插入新行。
- `Ctrl+Shift+[`：折叠选中的代码。
- `Ctrl+Shift+]`：展开选中的代码。
- `Ctrl+K+0`：展开所有折叠代码。
- `Ctrl+←`：以单词为单位向左移动光标。
- `Ctrl+→`：以单词为单位向右移动光标。
- `Shift+↑`：向上选中多行。
- `Ctrl+Shift+←`：以单词为单位向左选中文本。
- `Ctrl+Shift+↑`：交换光标所在行与上一行代码。
- `Ctrl+Alt+↑`：向上添加多行光标，以便同时编辑多行。
- `Ctrl+J`：将选中的多行代码合并为一行。
- `Ctrl+Shift+D`：复制光标所在整行，并插入到下一行。
- `Tab`：向右缩进。
- `Shift+Tab`：向左缩进。
- `Ctrl+K+K`：从光标处删除到行尾。
- `Ctrl+Shift+K`：删除整行。
- `Ctrl+/`：注释单行。
- `Ctrl+Shift+/`：注释多行。
- `Ctrl+K+U`：转换为大写。
- `Ctrl+K+L`：转换为小写。
