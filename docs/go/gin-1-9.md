# Gin 1.9

Gin 1.9 常见于已经上线一段时间的 Go API 项目。维护重点是稳定运行、依赖锁定和逐步升级。

## 适合场景

- 已经使用 Gin 1.9 的存量服务。
- 业务稳定，只做少量维护和修复。
- 暂时不方便升级 Go 或 Gin 的项目。

## 维护重点

| 项目 | 建议 |
| --- | --- |
| Go 版本 | 确认 `go.mod`、CI、服务器一致 |
| 依赖 | 使用 `go.mod` 和 `go.sum` 固定版本 |
| 路由 | 检查参数路由、分组路由、通配符路由 |
| 中间件 | 检查鉴权、跨域、日志、恢复中间件 |
| 参数绑定 | 检查 JSON、Form、Query 参数绑定 |

## 常用命令

查看当前 Gin 版本：

```sh
go list -m github.com/gin-gonic/gin
```

指定版本：

```sh
go get github.com/gin-gonic/gin@v1.9.1
```

整理依赖：

```sh
go mod tidy
```

## 升级建议

从 Gin 1.9 升级时，建议先升级到相邻版本并补充核心接口测试。重点测试登录鉴权、参数校验、文件上传、错误返回和中间件执行顺序。
