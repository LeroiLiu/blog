# Gin 1.12

Gin 1.12 适合新项目或计划使用较新 Go 环境的项目。使用前要先确认 Go 工具链、CI 和服务器环境是否满足要求。

## 适合场景

- 新 Go API 项目。
- 希望保持框架版本较新的项目。
- 可以同步升级 Go 工具链和部署环境的团队。

## 新项目建议

安装：

```sh
go get github.com/gin-gonic/gin@v1.12.0
```

查看版本：

```sh
go list -m github.com/gin-gonic/gin
```

整理依赖：

```sh
go mod tidy
```

## go.mod 示例

```go
module example.com/api

go 1.25

require github.com/gin-gonic/gin v1.12.0
```

如果服务器暂时无法升级 Go 工具链，不要贸然把 Gin 升到要求更高的版本。

## 升级检查

| 检查项 | 说明 |
| --- | --- |
| Go 工具链 | 本地、CI、服务器版本一致 |
| 依赖版本 | `go.mod`、`go.sum` 变化可控 |
| 路由 | 路径参数、路由组、通配符路由 |
| 中间件 | 鉴权、跨域、日志、恢复、限流 |
| 参数绑定 | JSON、Query、Form、URI |
| 测试 | 核心接口和错误分支覆盖 |

## 新项目结构建议

```txt
cmd/
api/
internal/
handler/
service/
repository/
middleware/
```

不要把所有逻辑都写进 `main.go` 或 handler。
