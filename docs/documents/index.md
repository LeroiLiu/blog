# 文档库总览

这里收集相对稳定、需要长期维护的文档。适合放规范、流程、接口设计、架构说明、排障手册和项目背景。

| 分类 | 内容 | 维护建议 |
| --- | --- | --- |

| 部署 | 环境变量、发布流程、回滚方案、监控检查 | 每次发布流程变化后更新 |

## 写作原则

文档应尽量回答三个问题：

1. 这件事是什么。
2. 为什么要这样做。
3. 遇到问题时如何判断和处理。

如果一段内容只在短期内有效，请在页面顶部注明适用范围和过期条件。
