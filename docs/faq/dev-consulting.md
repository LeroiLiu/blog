# 开发咨询 FAQ

## 可以咨询哪些问题

可以咨询网站开发、小程序开发、APP 开发、服务器维护、网站维护、Git 协作、接口联调、页面异常、部署失败、构建报错、对象存储、项目报价和需求梳理等问题。

## 咨询前需要准备什么

建议准备：

- 问题现象。
- 报错文本或截图。
- 复现步骤。
- 项目运行环境。
- 相关代码片段。
- 期望达到的结果。

信息越完整，判断越快。

## 项目报价怎么评估

报价通常取决于：

- 页面数量。
- 功能复杂度。
- 是否需要后台管理。
- 是否需要接口开发。
- 是否已有设计稿。
- 是否需要部署和长期维护。
- 交付周期是否紧急。

如果需求还比较模糊，可以先做需求梳理，再进入报价阶段。

## 平台数据维护包括什么

可维护微信视频号、微信公众号、小红书、抖音、快手等平台相关数据，包括账号资料、内容资料、作品信息、运营数据整理、页面信息更新和日常内容维护。
