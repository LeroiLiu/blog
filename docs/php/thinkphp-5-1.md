# ThinkPHP 5.1

ThinkPHP 5.1 是常见存量版本之一。维护时重点关注 Composer 依赖、运行缓存、路由配置、模型查询和 PHP 运行环境。

## 适合场景

- 已有 ThinkPHP 5.1 项目维护。
- 中小型后台系统、企业业务系统、接口项目。
- 需要保守迭代，不适合立即升级到 6.x 或 8.x 的项目。

## 维护重点

| 项目 | 建议 |
| --- | --- |
| Composer | 固定依赖版本，保留锁文件 |
| 配置 | 区分本地、测试、生产配置 |
| 路由 | 检查路由规则、URL 生成和伪静态 |
| 模型 | 注意查询条件、字段类型和关联关系 |
| 日志 | 保证异常可追踪 |

## 常用命令

安装依赖：

```sh
composer install
```

生产环境安装：

```sh
composer install --no-dev --optimize-autoloader
```

查看依赖：

```sh
composer show
```

## 常见问题

### 修改配置后不生效

可能是缓存没有清理，或者生产环境读取的是另一套配置。

### 数据库连接失败

检查数据库地址、账号、密码、端口、数据库名，以及服务器安全组和防火墙。

### 页面空白

先看 PHP 错误日志和 Web 服务错误日志，不要只看浏览器页面。

## 升级建议

如果项目还会长期维护，可以评估升级到 6.x 或 8.x。升级前先补齐核心流程测试，包括登录、权限、列表、表单、上传、导入导出、支付和定时任务。
