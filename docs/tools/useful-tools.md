## 后续维护分类

| 分类 | 可以记录的内容 |
| --- | --- |
| 开发工具 | API 调试、JSON 格式化、正则测试、编码转换 |
| 运维工具 | DNS 查询、端口检测、证书检查、Ping 和路由追踪 |
| 设计工具 | 图片压缩、颜色工具、字体工具、图标资源 |
| 平台工具 | 短信平台、对象存储、CDN、统计分析 |

每个工具最好记录用途、官网、是否需要登录、是否收费和使用注意事项。
