<p> 选择器是jQuery最基础的东西&#xff0c;本文中列举的选择器基本上囊括了所有的jQuery选择器&#xff0c;也许各位通过这篇文章能够加深对jQuery选择器的理解&#xff0c;它们本身用法就非常简单&#xff0c;我更希望的是它能够提升个人编写jQuery代码的效率。本文配合截图、代码和简单的概括对所有jQuery选择器进行了介绍&#xff0c;也列举出了一些需要注意和区分的地方。</p>
<h2> 一、基本选择器</h2>
<h4> 1. id选择器&#xff08;指定id元素&#xff09;</h4>
<p> 将<span>id&#61;&#34;one&#34;</span>的元素背景色设置为黑色。&#xff08;id选择器返单个元素&#xff09;</p>
<div class="language-javascript vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">javascript</span><pre class="vp-code" tabindex="0" v-pre><code>$(document).ready(
  function() {
    $("#one").css("background", "#000");
  }
);</code></pre></div>
<h4> 2. class选择器&#xff08;遍历css类元素&#xff09;</h4>
<p> 将<span>class&#61;&#34;cube&#34;</span>的元素背景色设为<span>黑色</span></p>
<div class="language-javascript vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">javascript</span><pre class="vp-code" tabindex="0" v-pre><code>$(document).ready(
  function() {
    $(".cube").css("background", "#000");
  }
);</code></pre></div>
<h4> 3. element选择器&#xff08;遍历html元素&#xff09;</h4>
<p> 将<span>p</span>元素的文字大小设置为12px</p>
<div class="language-javascript vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">javascript</span><pre class="vp-code" tabindex="0" v-pre><code>$(document).ready(
  function() {
    $("p").css("font-size", "12px");
  }
);</code></pre></div>
<h4> 4. * 选择器&#xff08;遍历所有元素&#xff09;</h4>
<div class="language-javascript vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">javascript</span><pre class="vp-code" tabindex="0" v-pre><code>$(document).ready(
  function() {
    $("form *").css("color", "#FF0000");
  }

<h4> 5. 并列选择器</h4>
