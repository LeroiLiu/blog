<h2><strong>为保证你能够不出问题的运行你的项目&#xff0c;请记住增加环境变量</strong></h2>
</blockquote>
<p>修改 <span><strong><code>~/.bash_profile</code>  </strong></span>文件 &#xff0c;在PATH后添加<span><strong>  :/<code>usr/local/bin</code></strong></span>&#xff0c;完整为&#xff1a;</p>
<div class="language-php vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">php</span><pre class="vp-code" tabindex="0" v-pre><code># .bash_profile
# Get the aliases and functions
if [ -f ~/.bashrc];
then. ~/.bashrc
fi
# User specific environment and startup programs
PATH = $PATH:$HOME/bin:/usr/local/bin
export PATH</code></pre></div>
<p>如果你有其他的配置项&#xff0c;则另说。</p>

<h2>2、react及redux项目</h2>
<p>请查看官网进行安装<a href="https://www.redux.org.cn/" rel="nofollow">https://www.redux.org.cn/</a></p>
<blockquote>
<p class="article-note"><span><strong>重点&#xff1a;在我们引用其他项目时&#xff0c;经常会出现错误。常见的有&#xff1a;</strong></span></p>
</blockquote>
<p><strong>2.1.1、问题特征&#xff1a;</strong><span>Npm install failed “cannot run in wd”</span></p>
<p><strong><span>2.1.2、解决方案&#xff1a;</span></strong>需要加上–unsafe-perm参数&#xff0c;完整如下&#xff1a;</p>
<div class="language-shell vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">shell</span><pre class="vp-code" tabindex="0" v-pre><code>npm install --unsafe-perm</code></pre></div>
<p>或是在<code>package.json</code>中添加&#xff1a;</p>
<div class="language-json vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">json</span><pre class="vp-code" tabindex="0" v-pre><code>"config": {
  "unsafe-perm": true
},</code></pre></div>
<p>官方解释为&#xff1a;</p>
<blockquote>
<p><em>If npm was invoked with root privileges, then it will change the uid to the user account or uid specified by the user config, which defaults to nobody. Set the unsafe-perm flag to run scripts with root privileges.</em></p>
</blockquote>
<p><strong>2.2.1、问题特征&#xff1a;</strong><span>npm WARN lifecycle dandelion_pro&#64;1.2.1~<em><u><strong>preinstall</strong></u></em>: cannot run in wd dandelion_pro&#64;1.2.1 <code>npm run npmcheckversion (wd&#61;/home/wwwroot/front.develop.loofii.com/starter-project)</code></span></p>
<p><strong><span>2.2.2、解决方案&#xff1a;</span></strong>注意上述红线加粗部分&#xff0c;当然这是一个warn&#xff0c;可视而不见&#xff0c;但是强迫症可以尝试按照下述方法进行修正&#xff1a;</p>
<div class="language-shell vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">shell</span><pre class="vp-code" tabindex="0" v-pre><code>npm run preinstall</code></pre></div>
<h2>3、使用nginx反向代理ip和端口</h2>
<p>按照个人开发习惯&#xff0c;应该不会有很高比例的人喜欢在web端直接使用ip和端口浏览网页吧&#xff1f;&#xff1f;&#xff1f;&#xff1f;&#xff1f;&#xff1f;&#xff1f;</p>
<p>前期准备&#xff1a;</p>
<blockquote>
<p>1、有一个域名&#xff0c;并已经将该域名解析到了服务器</p>
<p>2、服务器上已经安装了node和nginx</p>
</blockquote>
<p><span><strong>使用时请注意&#xff1a;将server_name替换成自己的域名&#xff0c;将proxy_pass替换成转发的<code>http(s)</code>://ip:port</strong></span></p>
<div class="language-nginx vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">nginx</span><pre class="vp-code" tabindex="0" v-pre><code>server {
  listen       80;
  server_name  node.leroi.com;
  #请替换成自己的域名
  location / {
    proxy_pass http://localhost:3000;
    #请替换成自己的 ip + port
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection 'upgrade';
    proxy_set_header Host $host;
    proxy_cache_bypass $http_upgrade;
  }
  error_page  500 502 503 504  /50x.html;
  #自己修改
  location = /50x.html {
    #自己注意修改
    root  /usr/share/nginx/html;
    #同理
  }
}</code></pre></div>
