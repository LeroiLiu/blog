<h2>什么是JSON&#xff1f;</h2>

<p> 　　JavaScript 对象表示法&#xff08;<span><strong><span>J</span></strong>ava<span><strong><span>S</span></strong>cript <span><strong><span>O</span></strong>bject <span><strong><span>N</span></strong>otation&#xff09;。</span></span></span></span></p>
<p> 　　JSON是一种轻量级的数据交换格式&#xff0c;某个JSON格式的文件内部譬如可以长成这样&#xff1a;</p>
<div>
<div>
<div class="language-json vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">json</span><pre class="vp-code" tabindex="0" v-pre><code>{
  "name": "hanzichi",
  "sex": "male"
}</code></pre></div>
</div>
</div>
<p> 　　看起来都是key-value的键值对&#xff0c;很像js的对象吧&#xff1f;没错&#xff0c;但同时JSON表示不服&#xff0c;我不能跟js的对象长成一样啊&#xff0c;我得有我自己的个性&#xff0c;于是规定键-值对中的键<strong><span>必须用双引号</span></strong>&#xff01;同时规定键-值对中的值的取值有一定要求&#xff1a;</p>
<p>
<strong><span>JSON 值可以是&#xff1a;</span></strong></p>
<ol>
<li>数字&#xff08;整数或浮点数&#xff09;</li>
<li>字符串&#xff08;<strong><span>在双引号中</span></strong>&#xff09;</li>
<li>逻辑值&#xff08;true 或 false&#xff09;</li>
<li>数组&#xff08;在方括号中&#xff09;</li>
<li>对象&#xff08;在花括号中&#xff09;</li>
<li>null</li>
</ol>
<p> 　　除以上6种外&#xff0c;再无其他&#xff0c;没有像js一样的undefined、NAN&#xff0c;JSON拒绝使用。</p>
<h2>如何使用JSON&#xff1f;</h2>
<p> 　　JSON一般以字符串的形式在数据交互过程中游走&#xff0c;so对于js而言&#xff0c;如何将json字符串和js对象之间进行相互转换显得尤为重要。</p>
<ul>
<li>eval大法&#xff08;json字符串 -&gt; js对象&#xff09;</li>
</ul>
<div>
<div>
<div class="language-javascript vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">javascript</span><pre class="vp-code" tabindex="0" v-pre><code>var jsonStr = '{"name": "hanzichi", "sex": "male"}';
var ans = eval("(" + jsonStr + ")");
console.log(ans.name, ans.sex);</code></pre></div>
</div>
</div>
<p> 　　eval 函数非常快&#xff0c;但是它可以编译任何 javascirpt 代码&#xff0c;这样的话就可能产生安全的问题。eval 的使用是基于传入的代码参数是可靠的假设下&#xff0c;有一些情况下&#xff0c;可能客户端是不可信任的。如果基于安全的考虑的话&#xff0c;最好是使用一个JSON解析器&#xff0c;一个JSON 解析器将只接受JSON文本&#xff0c;所以是更安全的&#xff0c;如下。</p>
<ul>
<li>JSON.parse&#xff08;json字符串 -&gt; js对象&#xff09;</li>
</ul>
<div>
<div>
<div class="language-javascript vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">javascript</span><pre class="vp-code" tabindex="0" v-pre><code>var jsonStr = '{"name": "hanzichi", "sex": "male"}';
var obj = JSON.parse(jsonStr);
console.log( typeof obj, obj);
// object Object {
  name: "hanzichi", sex: "male"}</code></pre></div>
</div>
</div>
<p> 　　第二个参数可以是函数&#xff0c;可以对值进行删改&#xff1a;</p>
<div>
<div>
<div class="language-javascript vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">javascript</span><pre class="vp-code" tabindex="0" v-pre><code>var jsonStr = '{"name": "hanzichi", "sex": "male", "age": 10}';
var obj = JSON.parse(jsonStr, function (key, value) {
  if (key === 'name' ) {
    return 'my name is ' + value;
  }
  return value;
});
console.log( typeof obj, obj);
// object Object {
  name: "my name is hanzichi", sex: "male", age: 10}</code></pre></div>
</div>
</div>
<ul>
<li>JSON.stringify&#xff08;js对象 -&gt; json字符串&#xff09;</li>
</ul>
<div>
<div>
<div class="language-javascript vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">javascript</span><pre class="vp-code" tabindex="0" v-pre><code>var obj = {
  name: 'hanzichi', sex:'male', age:'10'
}
;
var jsonStr = JSON.stringify(obj);
console.log(jsonStr);
// {
  "name":"hanzichi","sex":"male","age":"10"}</code></pre></div>
</div>
</div>
<p> 　　也可以加个参数&#xff0c;规定需要转化为json字符串的属性&#xff08;数组形式&#xff0c;跟数组同名的js对象属性才会被转换&#xff09;&#xff1a;</p>
<div>
<div>
<div class="language-javascript vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">javascript</span><pre class="vp-code" tabindex="0" v-pre><code>var obj = {
  name: 'hanzichi', sex:'male', age:'10'
}
;
var jsonStr = JSON.stringify(obj, [ 'name']);
console.log(jsonStr);
// {
  "name":"hanzichi"}</code></pre></div>
</div>
</div>
<p> 　　第二个参数也可以是个函数&#xff0c;可以删选符合条件的属性&#xff08;或者改变属性值&#xff0c;没有return表示放弃该属性&#xff0c;return的值表示该key在json字符串中的值&#xff09;</p>
<div>
<div>
<div class="language-javascript vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">javascript</span><pre class="vp-code" tabindex="0" v-pre><code>var obj = {
  name: 'hanzichi', sex:'male', age:'10'
}
;
var jsonStr = JSON.stringify(obj, function (key, value) {
  if (key === 'name' ) {
    return 'my name is ' + value;
  }
  return value;
});
console.log(jsonStr);
// {
  "name":"my name is hanzichi","sex":"male","age":"10"}</code></pre></div>
</div>
</div>
<p> 　　还可以有第三个参数&#xff0c;可以是数字或者字符串。</p>
<p> 　　如果是数字的话&#xff0c;表示缩进&#xff0c;数字大小超过10了按10处理。</p>
<div>
<div>
<div class="language-javascript vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">javascript</span><pre class="vp-code" tabindex="0" v-pre><code>var obj = {
  name: "hanzichi",
  sex: "male",
  age: "10"
};
var jsonStr = JSON.stringify(obj, null, 4);
console.log(jsonStr);</code></pre></div>
</div>
</div>
<p> 　　也可以是字符串&#xff0c;会在属性前加上这些字符串充当前缀&#xff0c;同样字符串长度超过10只截取10&#xff1a;</p>
<div>
<div>
<div class="language-javascript vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">javascript</span><pre class="vp-code" tabindex="0" v-pre><code>var obj = {
  name: "hanzichi",
  sex: "male",
  age: "10"
};
var jsonStr = JSON.stringify(obj, null, "pre");
console.log(jsonStr);</code></pre></div>
</div>
</div>

<h2><span class="article-heading-key">总结</span></h2>
<p> 　　当然传说中的ie8&#xff08;及以下&#xff09;因为某种缺陷不能使用JSON.parse()以及JSON.stringify()方法&#xff0c;而eval()又显得不安全&#xff0c;如果要兼容它们的话可以引用<a target="_blank" href="https://github.com/douglascrockford/JSON-js/blob/master/json2.js" rel="noopener noreferrer">json2.js</a>。</p>
