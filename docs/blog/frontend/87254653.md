<div class="migrated-article" v-pre>
<blockquote>
<p><strong>i18n</strong>&#xff08;取自英文单词 internationalization 的首末字符 i 和 n，中间 18 个字符用数字表示&#xff09;是“国际化”的简称。在资讯领域&#xff0c;国际化(i18n)指让产品&#xff08;出版物&#xff0c;软件&#xff0c;硬件等&#xff09;无需做大的改变就能够适应不同的语言和地区的需要。对程序来说&#xff0c;在不修改内部代码的情况下&#xff0c;能根据不同语言及地区显示相应的界面。<br />
在全球化的时代&#xff0c;国际化尤为重要&#xff0c;因为产品的潜在用户可能来自世界的各个角落。通常与i18n相关的还有L10n&#xff08;“本地化”的简称&#xff09;。</p>
</blockquote>

<div class="language-javascript vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">javascript</span><pre class="vp-code" tabindex="0" v-pre><code>({

<p><strong><code>config.js</code></strong></p>
<div class="language-javascript vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">javascript</span><pre class="vp-code" tabindex="0" v-pre><code>requirejs.config(
  {
    baseUrl: "./src/js",
    //require根路径
    paths: {
      i18n: "../../lib/i18n/i18n",
      //引入i18n插件路径
      jquery: "../../lib/jquery/dist/jquery.min"
      //引入jquery路径
    },
    config: {
      i18n: {
        locale: "en"
        //配制中英文信息，zh：中文,en：英文
      }
    }
  }
);</code></pre></div>
