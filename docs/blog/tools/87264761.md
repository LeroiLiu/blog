<h4><strong>首先说一下汉化</strong></h4>
<p>汉化插件需要用Package Control组件安装&#xff0c;所以首先我们要在Sublime上安装Package Control组件</p>
<ol>
<li>按Ctrl &#43; ~ 调出console</li>
<li>粘贴下列代码到命令行底部后回车 <div class="language-text vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">text</span><pre class="vp-code" tabindex="0" v-pre><code>import urllib.request,os,hashlib;

pf = 'Package Control.sublime-package';
ipp = sublime.installed_packages_path();
urllib.request.install_opener( urllib.request.build_opener( urllib.request.ProxyHandler()) );
by = urllib.request.urlopen( 'http://packagecontrol.io/' + pf.replace(' ', '%20')).read();
dh = hashlib.sha256(by).hexdigest();
print('Error validating download (got %s instead of %s), please try manual install' % (dh, h)) if dh != h else open(os.path.join( ipp, pf), 'wb' ).write(by)</code></pre></div>
</li>
<li>重启Sublime Text3</li>
<li>如果在 <span><code>首选项-&gt;浏览插件目录-&gt;User </code></span>中看到 <span>package control </span>这一项&#xff0c;则安装成功。</li>
<li>按Ctrl &#43; Shift &#43; P调出命令面板并输入Install Package回车                                                                                <img alt="" src="/images/blog/87264761/local-001.webp" /></li>

</ol>

<h4>Sublime Text3常用快捷键</h4>
<p><strong>Ctrl&#43;D</strong> 选中光标所占的文本&#xff0c;继续操作则会选中下一个相同的文本。</p>
<p><strong>Alt&#43;F3</strong> 选中文本按下快捷键&#xff0c;即可一次性选择全部的相同文本进行同时编辑。</p>
<p><strong>Ctrl&#43;L</strong> 选中整行&#xff0c;继续操作则继续选择下一行&#xff0c;效果和<strong>Shift&#43;↓</strong> 效果一样。</p>
<p><strong>Ctrl&#43;Shift&#43;L</strong> 先选中多行&#xff0c;再按下快捷键&#xff0c;会在每行行尾插入光标&#xff0c;即可同时编辑这些行。</p>
<p><strong>Ctrl&#43;Shift&#43;M</strong> 选择括号内的内容&#xff08;继续选择父括号&#xff09;。</p>
<p><strong>Ctrl&#43;M</strong> 光标移动至括号内结束或开始的位置。</p>
<p><strong>Ctrl&#43;Enter</strong> 在下一行插入新行。</p>
<p><strong>Ctrl&#43;Shift&#43;Enter</strong> 在上一行插入新行。</p>
<p><strong>Ctrl&#43;Shift&#43;[</strong> 选中代码&#xff0c;按下快捷键&#xff0c;折叠代码。</p>
<p><strong>Ctrl&#43;Shift&#43;]</strong> 选中代码&#xff0c;按下快捷键&#xff0c;展开代码。</p>
<p><strong>Ctrl&#43;K&#43;0</strong> 展开所有折叠代码。</p>
<p><strong>Ctrl&#43;←</strong> 向左单位性地移动光标&#xff0c;快速移动光标。</p>
<p><strong>Ctrl&#43;→</strong> 向右单位性地移动光标&#xff0c;快速移动光标。</p>
<p><strong>shift&#43;↑</strong> 向上选中多行。</p>
<p><strong>Ctrl&#43;Shift&#43;←</strong> 向左单位性地选中文本。</p>
<p><strong>Ctrl&#43;Shift&#43;↑</strong> 将光标所在行和上一行代码互换</p>
<p><strong>Ctrl&#43;Alt&#43;↑</strong> 向上添加多行光标&#xff0c;可同时编辑多行。</p>
<p><strong>Ctrl&#43;J</strong> 合并选中的多行代码为一行。</p>
<p><strong>Ctrl&#43;Shift&#43;D</strong> 复制光标所在整行&#xff0c;插入到下一行。</p>
<p><strong>Tab</strong> 向右缩进。<strong>Shift&#43;Tab</strong> 向左缩进。</p>
<p><strong>Ctrl&#43;K&#43;K</strong> 从光标处开始删除代码至行尾。<strong>Ctrl&#43;Shift&#43;K</strong> 删除整行。</p>
<p><strong>Ctrl&#43;/</strong> 注释单行。<strong>Ctrl&#43;Shift&#43;/</strong> 注释多行。</p>
<p><strong>Ctrl&#43;K&#43;U</strong> 转换大写。<strong>Ctrl&#43;K&#43;L</strong> 转换小写。</p>
