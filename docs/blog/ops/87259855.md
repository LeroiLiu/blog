# 快速将阿里云对象存储OOS挂载到服务器

<h2><a></a>1、挂载前注意事项</h2>
<p><strong>ossfs</strong> 使用有以下<strong>限制</strong>&#xff1a;</p>
<ul>
<li>不支挂载归档型Bucket。</li>
<li>编辑已上传文件会导致文件被重新上传。</li>
<li>元数据操作&#xff0c;例如<code>list directory</code>&#xff0c;因为需要远程访问OSS服务器&#xff0c;所以性能较差。</li>
<li>重命名文件/文件夹可能会出错。若操作失败&#xff0c;可能会导致数据不一致。</li>
<li>不适合高并发读/写的场景。</li>
<li>多个客户端挂载同一个<code>OSS bucket</code>时&#xff0c;数据一致性由您自行维护。例如&#xff0c;合理规划文件使用时间&#xff0c;避免出现多个客户端写同一个文件的情况。</li>
<li>不支持<code>hard link</code>。</li>
</ul>

<p>由于低版本的Linux系统内核版本比较低&#xff0c;ossfs进程在运行过程中容易出现掉线或者其他问题。因此建议用户将操作系统升级到CentOS 7.0或者Ubuntu 14.04以及以上版本。</p>

<h2><a></a>3、挂载</h2>
<p>设置<code>bucket name</code> 和 <code>AccessKeyId/Secret</code>信息&#xff0c;将其存放在<code>/etc/passwd-ossfs</code> 文件中。注意这个文件的权限必须正确设置&#xff0c;建议设为<code>640</code>。</p>
<div class="language-shell vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">shell</span><pre class="vp-code" tabindex="0" v-pre><code>echo my-bucket:my-access-key-id:my-access-key-secret&gt; /etc/passwd-
ossfs
chmod 640 /etc/passwd-ossfs</code></pre></div>
<p>将<code>OSS bucket</code> 挂载到指定目录。</p>
<div class="language-shell vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">shell</span><pre class="vp-code" tabindex="0" v-pre><code>ossfs my-bucket my-mount-point -ourl=my-oss-endpoint</code></pre></div>
<p>示例&#xff1a;<br /> 将<code>my-bucket</code>这个<code>bucket</code>挂载到<code>/tmp/ossfs</code>目录下&#xff0c;<code>AccessKeyId</code>是<code>faint</code>&#xff0c;<code>AccessKeySecret</code>是<code>123</code>&#xff0c;<code>OSS endpoint</code>是<code>http://oss-cn-hangzhou.aliyuncs.com</code></p>
<div class="language-shell vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">shell</span><pre class="vp-code" tabindex="0" v-pre><code>echo my-bucket:faint:123&gt; /etc/passwd-
ossfs
chmod 640 /etc/passwd-
ossfs
mkdir /tmp/
ossfs
ossfs my-bucket /tmp/
ossfs -ourl=http://oss-cn-hangzhou.aliyuncs.com</code></pre></div>
<p class="article-note"><strong>注意</strong> 如果您使用从阿里云购买的云服务器&#xff08;<code>ECS</code>&#xff09;来提供<code>ossfs</code>服务&#xff0c;您<code>可以使用内网域名</code>&#xff0c;在这个示例中您可以将<code>OSS</code>
<code>endpoint</code> 改为 <code>oss-cn-hangzhou-internal.aliyuncs.com</code>&#xff0c;<code>这样可以节省流量费用</code>。</p>
<h2><a></a>4、卸载</h2>
<div class="language-shell vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">shell</span><pre class="vp-code" tabindex="0" v-pre><code>fusermount -u /tmp/ossfs</code></pre></div>
