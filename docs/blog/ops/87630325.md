# CentOS7升级Python2.7.5至2.7.13版本

::: info 历史博客说明
本文为 Leroi 的历史博客文章，原发布于 CSDN，现迁移并重新整理到本站。

原博客地址（CSDN）：[https://blog.csdn.net/Leroi_Liu/article/details/87630325](https://blog.csdn.net/Leroi_Liu/article/details/87630325)
:::

<div class="migrated-article" v-pre>
<blockquote>
<p>CentOS7系统目前默认python环境版本号为2.7.5&#xff0c;在实际的开发、测试环境中我们可能需要2.7.13的版本&#xff0c;但是<strong>Centos操作系统自带软件可能依赖python2.7.5版本</strong>&#xff0c;故原版本不能删除&#xff0c;我们只能python基础版本与高版本并存&#xff0c;以下为具体步骤&#xff1a;</p>
</blockquote>
<h4>1、查看Centos版本及python版本&#xff1a;</h4>
<div class="language-shell vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">shell</span><pre class="vp-code" tabindex="0" v-pre><code>[root@localhost ~]# cat /etc/centos-release
CentOS Linux release 7.3.1611 (Core)
[root@localhost ~]# python -V
Python 2.7.5</code></pre></div>
<p><img alt="" height="63" src="/images/blog/87630325/local-001.png" width="329" /></p>
<h4>2、从官网下载相应的Python包&#xff08;以2.7.13为例&#xff09;&#xff1a;</h4>
<div class="language-shell vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">shell</span><pre class="vp-code" tabindex="0" v-pre><code>wget https://www.python.org/ftp/python/2.7.13/Python-2.7.13.tgz</code></pre></div>
<p><img alt="" height="178" src="/images/blog/87630325/local-002.png" width="615" /></p>
<h4>3、解压Python包</h4>
<div class="language-shell vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">shell</span><pre class="vp-code" tabindex="0" v-pre><code>tar -zxvf Python-2.7.13.tgz</code></pre></div>
<h4>4、配置编译环境</h4>
<div class="language-shell vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">shell</span><pre class="vp-code" tabindex="0" v-pre><code>yum install gcc* openssl openssl-devel ncurses-devel.x86_64  bzip2-devel sqlite-devel python-devel zlib</code></pre></div>
<h4>5、配置、编译、安装</h4>
<div class="language-shell vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">shell</span><pre class="vp-code" tabindex="0" v-pre><code>[root@localhost ~]#
cd Python-2.7.13
[root@localhost Python-2.7.13]# ./configure --prefix=/usr/local
#[配置]指定可执行文件、库文件、配置文件、资源文件的安装路径。若没有权限加
sudo
[root@localhost Python-2.7.13]#
make
#编译
[root@localhost Python-2.7.13]#
make altinstall
#不要使用
make install，否则会覆盖系统自带python</code></pre></div>
<h4>6、安装后环境检查</h4>
<p><strong>备份旧版本</strong></p>
<div class="language-shell vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">shell</span><pre class="vp-code" tabindex="0" v-pre><code>[root@localhost Python-2.7.13]# mv /usr/bin/python /usr/bin/python2.7.5</code></pre></div>
<p><strong>访问老版本</strong></p>
<div class="language-shell vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">shell</span><pre class="vp-code" tabindex="0" v-pre><code>[root@localhost bin]# python2.7.5</code></pre></div>
<p><strong>链接新版本</strong></p>
<div class="language-shell vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">shell</span><pre class="vp-code" tabindex="0" v-pre><code>[root@localhost Python-2.7.13]# ln -s /usr/local/bin/python2.7 /usr/bin/python</code></pre></div>
<p><strong>查看当前版本</strong></p>
<div class="language-shell vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">shell</span><pre class="vp-code" tabindex="0" v-pre><code>[root@localhost bin]# python -V
Python 2.7.13</code></pre></div>
<p><strong>修改yum配置</strong></p>
<blockquote>
<p><span><strong>将下列两个文件首行的     #!<code>/usr/bin/python</code>    都改为     #!<code>/usr/bin/python2.7.5</code></strong></span></p>
</blockquote>
<div class="language-shell vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">shell</span><pre class="vp-code" tabindex="0" v-pre><code>[root@localhost bin]# vim /usr/bin/
yum
[root@localhost bin]# vim /usr/libexec/urlgrabber-ext-down</code></pre></div>
<h4>7、安装pip</h4>
<div class="language-shell vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">shell</span><pre class="vp-code" tabindex="0" v-pre><code>wget https://bootstrap.pypa.io/get-pip.py
python get-pip.py</code></pre></div>
