# 安装并配置ROS环境

<h2>1、安装ROS</h2>
<h3>1.1、配置Ubuntu存储库</h3>
<p>配置Ubuntu存储库允许&#34;restricted,&#34; &#34;universe,&#34; and &#34;multiverse.&#34;。</p>
<h3>1.2、配置<span>sources.list</span></h3>
<p>设置计算机软件源来自packages.ros.org。按照对应Ubuntu版本选择ROS版本和软件源</p>
<p><img alt="" src="/images/blog/82352961/local-001.png" /></p>
<div class="language-shell vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">shell</span><pre class="vp-code" tabindex="0" v-pre><code>sudo sh -c '
echo "deb http://packages.ros.org/ros/ubuntu $(lsb_release -sc) main"&gt; /etc/apt/sources.list.d/ros-latest.list'</code></pre></div>
<h3>1.3、设置KEY</h3>
<div class="language-shell vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">shell</span><pre class="vp-code" tabindex="0" v-pre><code>sudo apt-key adv --keyserver hkp://ha.pool.sks-keyservers.net:80 --recv-key 421C365BD9FF1F717815A3895523BAEEB01FA116</code></pre></div>
<p>如果在连接密钥服务器时遇到问题&#xff0c;可以尝试在上一个命令中替换hkp://pgp.mit.edu:80或hkp://keyserver.ubuntu.com:80。</p>
<h3>1.4、安装</h3>
<h4>1.4.1、更新软件源</h4>
<div class="language-shell vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">shell</span><pre class="vp-code" tabindex="0" v-pre><code>sudo apt-get update</code></pre></div>
<h4>1.4.2、任选其一即可</h4>
<p><strong>Desktop-Full Install: (推荐)</strong> : ROS, <a href="http://wiki.ros.org/rqt" rel="nofollow">rqt</a>, <a href="http://wiki.ros.org/rviz" rel="nofollow">rviz</a>, robot-generic libraries, 2D/3D simulators and 2D/3D perception</p>
<div class="language-shell vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">shell</span><pre class="vp-code" tabindex="0" v-pre><code>sudo apt-get install ros-melodic-desktop-full</code></pre></div>
<p><strong>Desktop Install: </strong>ROS, <a href="http://wiki.ros.org/rqt" rel="nofollow">rqt</a>, <a href="http://wiki.ros.org/rviz" rel="nofollow">rviz</a>, and robot-generic libraries</p>
<div class="language-shell vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">shell</span><pre class="vp-code" tabindex="0" v-pre><code>sudo apt-get install ros-melodic-desktop</code></pre></div>
<p><strong>ROS-Base: (Bare Bones)</strong> ROS package, build, and communication libraries. No GUI tools.</p>
<div class="language-shell vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">shell</span><pre class="vp-code" tabindex="0" v-pre><code>sudo apt-get install ros-melodic-ros-base</code></pre></div>
<p><strong>Individual Package:</strong> You can also install a specific ROS package (replace underscores with dashes of the package name):</p>
<div class="language-shell vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">shell</span><pre class="vp-code" tabindex="0" v-pre><code>sudo apt-get install ros-melodic-PACKAGE</code></pre></div>
<p>eg:</p>
<div class="language-shell vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">shell</span><pre class="vp-code" tabindex="0" v-pre><code>sudo apt-get install ros-melodic-slam-gmapping</code></pre></div>
<p>寻找可用的软件包&#xff1a;</p>
<div class="language-shell vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">shell</span><pre class="vp-code" tabindex="0" v-pre><code>apt-cache search ros-melodic</code></pre></div>
<h3>1.5、初始化rosdep</h3>
<p>在使用ROS之前&#xff0c;您需要初始化rosdep。rosdep使您可以轻松地为要编译的源安装系统依赖项&#xff0c;并且需要在ROS中运行一些核心组件。</p>
<div class="language-shell vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">shell</span><pre class="vp-code" tabindex="0" v-pre><code>sudo rosdep init
rosdep update</code></pre></div>
<h3>1.6、<span>环境设置</span></h3>
<p>每次启动新shell时ROS环境变量自动添加到bash会话</p>
<div class="language-shell vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">shell</span><pre class="vp-code" tabindex="0" v-pre><code>echo "
source /opt/ros/melodic/setup.bash"&gt;&gt; ~/.bashrc
source ~/.bashrc</code></pre></div>
<p><em>如果安装了多个ROS分发&#xff0c;<code>~/.bashrc</code>必须只能对你当前正在使用的版本source操作</em></p>
<p>如果您只想更改当前shell的环境&#xff0c;而不是上面的类型&#xff0c;则可以键入&#xff1a;</p>
<div class="language-shell vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">shell</span><pre class="vp-code" tabindex="0" v-pre><code>source /opt/ros/melodic/setup.bash</code></pre></div>
<p>如果使用zsh而不是bash&#xff0c;则需要运行以下命令来设置shell&#xff1a;</p>
<div class="language-shell vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">shell</span><pre class="vp-code" tabindex="0" v-pre><code>echo "
source /opt/ros/melodic/setup.zsh"&gt;&gt; ~/.zshrc
source ~/.zshrc</code></pre></div>
<h4>1.7、构建包的依赖关系</h4>
<p><span>到目前为止&#xff0c;您已经安装了运行核心ROS软件包所需的内容。要创建和管理自己的ROS工作区&#xff0c;可以单独分发各种工具和要求。例如&#xff0c;<a href="http://wiki.ros.org/rosinstall" rel="nofollow">rosinstall</a>是一种常用的命令行工具&#xff0c;使您可以使用一个命令轻松下载ROS包的许多源树。要安装此工具和其他依赖项以构建ROS包&#xff0c;请运行&#xff1a;</span></p>
<div class="language-shell vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">shell</span><pre class="vp-code" tabindex="0" v-pre><code>sudo apt-get install python-rosinstall python-rosinstall-generator python -wstool build-essential</code></pre></div>
<h4>1.8、Build farm status</h4>
<p>The packages that you installed were built by the <a href="http://build.ros.org/" rel="nofollow">ROS build farm</a>. You can check the status of individual packages <a href="http://repositories.ros.org/status_page/ros_melodic_default.html" rel="nofollow">here</a>.</p>
