<h2><a></a>安装开发环境</h2>
<p>按照个人使用习惯安装LNMP、WNMP、LAMP、WAMP&#xff0c;LNMPA等开发环境。下面以LNMP和WNMP开发环境为例。</p>
<p>关于Linux Server 和 Windows Server之间的选择&#xff0c;可以按照实际项目规模和个人使用习惯来判断。两者各具优点&#xff1a;</p>
<p>Linux本身就是网络操作系统并与unix兼容且多用户多进程&#xff0c;开放完整成熟的社区&#xff0c;模块化&#xff0c;可裁剪&#xff0c;用户管理严格&#xff0c;病毒难以破坏。</p>
<p>Windows单用户伪多用户系统&#xff0c;用户管理混乱&#xff0c;漏洞百出&#xff0c;而且常常蓝屏。</p>
<p>当然&#xff0c;图形化界面更容易初学者上手&#xff0c;也是一个不错的选择。</p>
<h3><a></a>Linux平台</h3>
<p>Linux 平台可以使用 <a href="https://lnmp.org/" rel="nofollow">LNMP一键安装包</a>&#xff1a;</p>
<p>LNMP一键安装包是一个用Linux Shell编写的可以为<code>CentOS/RHEL/Fedora/Aliyun/Amazon</code>、<code>Debian/Ubuntu/Raspbian/Deepin/Mint</code> Linux VPS或独立主机安装<code>LNMP(Nginx/MySQL/PHP)、LNMPA(Nginx/MySQL/PHP/Apache)、LAMP(Apache/MySQL/PHP)</code>生产环境的Shell程序。</p>
<h4><a></a>简而言之</h4>
<p>如果不想查看<a href="https://lnmp.org/" rel="nofollow">LNMP一键安装包</a>内容&#xff0c;可以按照以下步骤进行&#xff1a;</p>
<p><strong>1、使用<a href="https://www.vpser.net/other/putty-ssh-linux-vps.html" rel="nofollow">putty</a>或类似的SSH工具登陆VPS或服务器&#xff1a;</strong></p>
<p>登陆后运行&#xff1a;<code>screen -S lnmp</code><br /> 如果提示screen: command not found 命令不存在可以执行&#xff1a;<code>yum install screen</code> 或 <code>apt-get install screen</code>安装&#xff0c;详细内容可以查看<a href="https://www.vpser.net/manage/run-screen-lnmp.html" rel="nofollow">screen教程</a>。</p>
<p><strong>2、下载并安装LNMP一键安装包</strong></p>
<div class="language-shell vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">shell</span><pre class="vp-code" tabindex="0" v-pre><code>wget http://soft.vpser.net/lnmp/lnmp1.5.tar.gz -cO lnmp1.5.tar.gz &amp;&amp; tar zxf lnmp1.5.tar.gz &amp;&amp; cd lnmp1.5 &amp;&amp; ./install.sh  lnmp</code></pre></div>
<h3><a></a>Windows平台</h3>
<p>Windows平台由于图形化界面&#xff0c;容易上手&#xff0c;无论是WNMP或者是WAMP都可以直接使用软件解决。这里推荐两款软件&#xff1a;<a href="http://phpstudy.php.cn/" rel="nofollow">phpStudy</a>和<a href="https://sourceforge.net/projects/wampserver/" rel="nofollow">WAMP Server</a></p>
<p>当然&#xff0c;这里更推荐<a href="http://phpstudy.php.cn/" rel="nofollow">phpStudy</a>&#xff0c;原因有二&#xff1a;</p>
<ol>
<li><a href="http://www.wampserver.com" rel="nofollow">WAMP</a>安装涉及配置较多&#xff0c;安装更容易出现问题&#xff0c;且使用不便。</li>
<li><a href="http://phpstudy.php.cn/" rel="nofollow">phpStudy</a>安装简单&#xff0c;配置较少&#xff0c;且集成了Nginx、IIS、Apache、nts等服务环境。</li>
</ol>
<p>鉴于以上&#xff0c;更偏向使用<a href="http://phpstudy.php.cn/" rel="nofollow">phpStudy</a></p>
<p><strong>接下来&#xff0c;将以<code>Linux(CentOS7)</code>&#43;Nginx&#43;MySQL&#43;PHP7的开发环境进行…</strong></p>
<h2><a></a>部署网站根目录</h2>
<h3><a></a>准备工作&#xff1a;</h3>
<ol>
<li>服务器必备&#xff0c;例如阿里云、百度云、AWS等&#xff0c;会提供服务器公网IP&#xff0c;这里假设以47.63.13.2为例。</li>
<li>一个域名&#xff0c;解析到服务器&#xff0c;例如&#xff1a;odin.com解析到47.63.13.2&#xff0c;这里一般在阿里云、百度云或者AWS都有入口。</li>
</ol>

<h2><a></a>安装laravel Dingo</h2>
<p>添加一些基础文件&#xff0c;便于后期操作。Dingo/Api 的更多说明可以查看 <a href="https://github.com/dingo/api/wiki">Dingo/Api</a> 维基。</p>
<p>修改<code>/home/wwwroot/odin.com/odin/composer.json</code></p>
<p>在“require”下添加<code>&#34;dingo/api&#34;: &#34;2.0.0-alpha1&#34;,&#34;predis/predis&#34;: &#34;^1.1&#34;</code>或者复制如下&#xff1a;</p>
<div class="language-json vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">json</span><pre class="vp-code" tabindex="0" v-pre><code>"require": {
  "php": "^7.1.3",
  "fideloper/proxy": "^4.0",
  "laravel/framework": "5.7.*",
  "laravel/tinker": "^1.0",
  "dingo/api": "2.0.0-alpha1",
  "predis/predis": "^1.1"
},</code></pre></div>
<p>在“autoload”下添加“files”&#xff0c;或者复制如下&#xff1a;<br /> 当然&#xff0c;你需要首先在<code>app/Helpers</code>目录下创建<code>common.php</code>、<code>const.php</code>、<code>request.php</code>文件。如果没有<code>Helpers</code>目录可以新建。</p>
<div class="language-json vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">json</span><pre class="vp-code" tabindex="0" v-pre><code>"autoload": {
  "psr-4": {
    "App\\": "app/"
  },
  "files": [
    "app/Helpers/common.php",
    "app/Helpers/const.php",
    "app/Helpers/request.php"
  ],
  "classmap": [
    "database/seeds",
    "database/factories"
  ]
},</code></pre></div>
<p>加载<code>common.php</code>、<code>const.php</code>、<code>request.php</code></p>
<div class="language-shell vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">shell</span><pre class="vp-code" tabindex="0" v-pre><code>[root@localhost odin]# composer dump-auto</code></pre></div>
<p>安装<code>dingo/api</code>和<code>predis/predis</code></p>
<div class="language-shell vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">shell</span><pre class="vp-code" tabindex="0" v-pre><code>[root@localhost odin]# composer update</code></pre></div>
<p>在<code>.env</code>文件中添加以下文本内容&#xff1a;</p>
<div class="language-text vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">text</span><pre class="vp-code" tabindex="0" v-pre><code>API_STANDARDS_TREE=vnd
API_SUBTYPE=myapp
API_PREFIX=api
API_VERSION=v1
API_DEFAULT_FORMAT=json
API_DEBUG=true
API_NAME="api"
API_CONDITIONAL_REQUEST=false
API_STRICT=false</code></pre></div>
<p>编辑<code>/home/wwwroot/odin.com/odin/config/app.php</code>的<code>providers</code>下添加<code>Dingo\Api\Provider\LaravelServiceProvider::class</code></p>
<p>编辑<code>/home/wwwroot/odin.com/odin/routes/api.php</code>为&#xff1a;</p>
<div class="language-php vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">php</span><pre class="vp-code" tabindex="0" v-pre><code>use Illuminate\Http\Request;
$api = app('Dingo\Api\Routing\Router');
$api-&gt;version('v1', ['namespace' =&gt; 'App\Http\Controllers\Api'], function ($api) {
  $api-&gt;any('/', 'TestController@test');
});</code></pre></div>
<p>编辑<code>/home/wwwroot/odin.com/odin/app/Http/Controllers/Api/TestController.php</code>为&#xff1a;</p>
<div class="language-php vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">php</span><pre class="vp-code" tabindex="0" v-pre><code>namespace App\Http\Controllers\api;
use Illuminate\Http\Request;
use App\Http\Controllers\Controller;
use Illuminate\Support\Facades\DB;
use Illuminate\Support\Facades\Redis;
use App\Http\Requests\LoRa\Test;
class TestController extends Controller
{
  public function test()
  {
    var_dump("test");
  }
}</code></pre></div>
