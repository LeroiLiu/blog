<h2> 2、搭建Ngrok服务</h2>
<h3>2.1、下载ngrok源码</h3>
<div class="language-shell vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">shell</span><pre class="vp-code" tabindex="0" v-pre><code>cd /usr/local/src
git clone https://github.com/inconshreveable/ngrok.git</code></pre></div>
<h3>2.2、生成证书</h3>
<blockquote>
<p>在自生成证书时需要域名&#xff08;二级域名也可以&#xff0c;本人已经验证&#xff09;解析到服务器上&#xff0c;现在以”<span><strong>ngrok.taomeng.tech</strong></span>”为例:</p>
</blockquote>
<div class="language-php vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">php</span><pre class="vp-code" tabindex="0" v-pre><code>cd ngrok
#这里修改为自己的域名
export NGROK_DOMAIN = "ngrok.taomeng.tech"
openssl genrsa -out rootCA.key 2048
openssl req -x509 -new -nodes -key rootCA.key -subj "/CN = $NGROK_DOMAIN" -days 5000 -out rootCA.pem
openssl genrsa -out device.key 2048
openssl req -new -key device.key -subj "/CN = $NGROK_DOMAIN" -out device.csr
openssl x509 -req -in device.csr -CA rootCA.pem -CAkey rootCA.key -CAcreateserial -out device.crt -days 5000</code></pre></div>
<p>将新生成的证书&#xff0c;替换掉<code>assets/client/tls</code>下的证书:</p>
<div class="language-shell vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">shell</span><pre class="vp-code" tabindex="0" v-pre><code>cp rootCA.pem assets/client/tls/ngrokroot.crt
cp device.crt assets/server/tls/snakeoil.crt
cp device.key assets/server/tls/snakeoil.key</code></pre></div>
<h3>2.3、编译生成ngrokd&#xff08;服务端&#xff09;</h3>
<div class="language-shell vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">shell</span><pre class="vp-code" tabindex="0" v-pre><code>#这里是交叉编译，linux系统GOOS=linux,64位系统GOARCH=amd64，32位系统GOARCH=386
#当前系统可用
go env查看
GOOS=linux GOARCH=amd64
make release-server</code></pre></div>
<p>编译成功后在当前目录的bin目录下可找到ngrokd文件</p>
<h3>2.4、编译生成ngrok&#xff08;客户端&#xff09;</h3>
<blockquote>
<p>我这里生成windows下的客户端。为go生成交叉编译环境&#xff0c;执行如下命令&#xff1a;</p>
</blockquote>
<div class="language-shell vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">shell</span><pre class="vp-code" tabindex="0" v-pre><code>#这里是交叉编译，linux系统GOOS=linux,64位系统GOARCH=amd64，32位系统GOARCH=386
#当前系统可用
go env查看
GOOS=windows GOARCH=amd64 make release-client</code></pre></div>
<p>一般情况下是可以顺利成功编译出windows客户端的&#xff0c;成功会在bin目录下看到windows_amd64文件夹&#xff0c;复制到windows电脑上即可启动。</p>
<h3>2.5、启动</h3>
<h4>2.5.1、服务端</h4>
<div class="language-shell vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">shell</span><pre class="vp-code" tabindex="0" v-pre><code>./bin/ngrokd -tlsKey="assets/server/tls/snakeoil.key" -tlsCrt="assets/server/tls/snakeoil.crt" -domain="ngrok.taomeng.tech"  -httpAddr=":8081" -httpsAddr=":8082" -tunnelAddr=":8083"</code></pre></div>
<h4>2.5.2、客户端</h4>
<p>在windows_amd64目录下新建一个ngrok.cfg文件&#xff0c;内容如下&#xff1a;</p>
<div class="language-text vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">text</span><pre class="vp-code" tabindex="0" v-pre><code>server_addr: "ngrok.taomeng.tech:8083"
trust_host_root_certs: false
tunnels: http: subdomain: "www"
proto: http: "8090"
https: subdomain: "www"
proto: https: "8091"
mstsc: remote_port: 3389
proto: tcp: "127.0.0.1:3389"</code></pre></div>
<p>然后打开CMD输入<code>ngrok.exe</code>文件夹&#xff1a;</p>
<div class="language-shell vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">shell</span><pre class="vp-code" tabindex="0" v-pre><code>ngrok.exe -config ngrok.cfg start http https mstsc</code></pre></div>
<p class="article-note">提示<span><strong>online</strong></span>即连接成功</p>
<h4>2.5.3、如何远程</h4>
<p>使用windows远程桌面&#xff0c;输入主机为&#xff1a;<strong><span>ngrok.taomeng.tech</span></strong>即可。</p>

<blockquote>
<p class="article-result"><strong>解决方法&#xff1a;前往go安装目录的bin目录下找到go-bindata&#xff0c;将他移动到<code>ngrok/bin</code>下 &#xff08;没有bin&#xff0c;可新建一个)   </strong></p>
</blockquote>
<h3>3.2、编译服务端时&#xff1a;　</h3>
<div class="language-text vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">text</span><pre class="vp-code" tabindex="0" v-pre><code>package code.google.com/p/log4go: Get https://code.google.com/p/log4go/source/checkout?repo=: dial tcp 216.58.197.110:443: i/o timeout</code></pre></div>
<p> 因为google被墙&#xff0c;如果服务器不在墙外或者没有FQ则无法访问到<a href="http://code.google.com/" rel="nofollow">code.google.com</a>.</p>
<blockquote>
<p class="article-result"><strong>解决方法&#xff1a;在 <code>ngrok/src/ngrok/log</code> 目录下找到 logger.go 文件&#xff0c;修改其中第4或5行的&#xff1a;log &#34;<a href="http://code.google.com/p/log4go" rel="nofollow">code.google.com/p/log4go</a>”为log &#34;<a href="http://github.com/keepeye/log4go">github.com/keepeye/log4go</a>&#34;  </strong></p>
</blockquote>
