# <code>$_FILES</code> name和tmp_name有什么区别

::: info 历史博客说明
本文为 Leroi 的历史博客文章，原发布于 CSDN，现迁移并重新整理到本站。

原博客地址（CSDN）：[https://blog.csdn.net/Leroi_Liu/article/details/72934267](https://blog.csdn.net/Leroi_Liu/article/details/72934267)
:::

<div class="migrated-article" v-pre>
<p><span><code>$_FILES[字段名]</code>[name]</span>——保存的文件在上传者机器上的文件名&#xff0c;</p>
<p><span><code>$_FILES[字段名]</code>[tmp_name]</span>——保存的是文件上传到服务器临时文件夹之后的文件名</p>
<br />
<br />
    一般我们应该从<code>$_FILES[字段名]</code>[name]获取文件名、扩展名等信息&#xff0c;和程序规定的文件夹一起组装成为目标文件名&#xff0c;然后把临时文件<code>$_FILES[字段名]</code>[tmp_name]移动过去。<br />
</div>
