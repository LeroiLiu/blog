# Laravel常用命令行中文版

<div class="migrated-article" v-pre>
<h2>0、new一个Laravel项目</h2>
<div class="language-shell vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">shell</span><pre class="vp-code" tabindex="0" v-pre><code>composer create-project laravel/laravel project-name --prefer-dist "5.5.*"</code></pre></div>
<h2>1、生成控制器</h2>
<div class="language-shell vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">shell</span><pre class="vp-code" tabindex="0" v-pre><code>php artisan make:controller ArticleController</code></pre></div>
<p>对应的会在<code>app/http/controllers</code>下面生成<code>ArticleController.php</code>这个控制器。</p>
<h2>2、使用RESTFUL生成控制器&#xff0c;这个很有用哦&#xff01;</h2>
<div class="language-shell vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">shell</span><pre class="vp-code" tabindex="0" v-pre><code>php artisan make:controller ArticleController --resource</code></pre></div>
<div class="language-php vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">php</span><pre class="vp-code" tabindex="0" v-pre><code>Route::resource('article', 'ArticleController');</code></pre></div>
<p>为什么用 <code>--resource</code> 参数&#xff0c;因为我们在做一个后台的时候&#xff0c;涉及到增删改查操作&#xff0c;而这些操作可以通过 <code>--resource</code> 直接生成对应方法。<code>Route::resource</code> 其实就是生成了快捷的资源路由&#xff0c;让我们本来需要写的 <code>get</code>、<code>post</code>、<code>delete</code>、<code>patch</code> 直接用 restful 方式一键生成。</p>
<h3>需要注意的是：<code>index</code> 是列表，<code>store</code> 是新增，<code>show</code> 是详情，<code>update</code> 是更新，<code>destroy</code> 是删除。</h3>
<p>利用命令可以查看当前注册的路由有哪些&#xff1a;</p>
<div class="language-shell vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">shell</span><pre class="vp-code" tabindex="0" v-pre><code>php artisan route:list</code></pre></div>
<h2>3、生成模型</h2>
<div class="language-shell vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">shell</span><pre class="vp-code" tabindex="0" v-pre><code>php artisan make:model User -m</code></pre></div>
<p>默认的模型文件生成在App目录&#xff0c;如果要生成在其他目录要带目录&#xff0c;比方说我把Model放到了<code>App/Models/</code>目录&#xff0c;则执行</p>
<div class="language-shell vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">shell</span><pre class="vp-code" tabindex="0" v-pre><code>php artisan make:model Models/Question -m</code></pre></div>
<p><code>-m</code> 参数为生成模型同时生成数据库创建文件。</p>
<h2>4、PHP数据表维护&#xff08;迁移&#xff09;</h2>
<p>新建迁移&#xff1a;</p>
<div class="language-shell vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">shell</span><pre class="vp-code" tabindex="0" v-pre><code>php artisan make:migration create_users_table</code></pre></div>
<p>新的迁移位于 <code>database/migrations</code> 目录下&#xff0c;每个迁移文件名都包含时间戳&#xff0c;从而允许 Laravel 判断其顺序。<br /> <code>--table</code> 和 <code>--create</code> 选项可以用于指定表名&#xff0c;以及该迁移是否要创建一个新的数据表。这些选项只需要放在上述迁移命令后面并指定表名&#xff1a;</p>
<div class="language-shell vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">shell</span><pre class="vp-code" tabindex="0" v-pre><code>php artisan make:migration add_votes_to_users_table --table=users
php artisan make:migration create_users_table --create=users</code></pre></div>
<p>运行迁移&#xff1a;</p>
<div class="language-shell vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">shell</span><pre class="vp-code" tabindex="0" v-pre><code>php artisan migrate</code></pre></div>
<h2>5、填充数据</h2>
<p>新建填充&#xff1a;</p>
<div class="language-shell vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">shell</span><pre class="vp-code" tabindex="0" v-pre><code>php artisan make:seeder UserTableSeeder</code></pre></div>
<p>运行填充器&#xff1a;</p>
<div class="language-shell vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">shell</span><pre class="vp-code" tabindex="0" v-pre><code>php artisan db:seed
php artisan db:seed --class=UserTableSeeder</code></pre></div>
<p>你还可以使用migrate:refresh命令来填充数据库&#xff0c;该命令还可以回滚并重新运行迁移&#xff0c;这在需要完全重建数据库时很有用&#xff1a;</p>
<div class="language-shell vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">shell</span><pre class="vp-code" tabindex="0" v-pre><code>php artisan migrate:refresh --seed</code></pre></div>
<p>如果需要插卡全部命令&#xff1a; <br /> 可以运用如下命令&#xff1a;</p>
<div class="language-shell vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">shell</span><pre class="vp-code" tabindex="0" v-pre><code>php artisan</code></pre></div>
