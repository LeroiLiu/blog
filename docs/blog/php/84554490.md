<p>In this article, we will look at using JWT to secure our Laravel APIs.</p>
<p>JSON Web Token (JWT) is an open standard that allows two parties to securely send data and information as JSON objects. This information can be verified and trusted because it is digitally signed.</p>
<p>JWT authentication has aided the wider adoption of stateless API services. It makes it convenient to authorise and verify clients accessing API resources. It is a critical part of the authentication system in javascript powered applications.</p>

<h3>Creating our routes</h3>
<p>Before we define our API routes, we need to create a <code>JwtM&#96;&#96;iddleware</code> which will protect our routes. Run this command via your terminal.</p>
<div class="language-shell vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">shell</span><pre class="vp-code" tabindex="0" v-pre><code>$ php artisan make:middleware JwtMiddleware</code></pre></div>
<p>This will create a new middleware file inside our Middleware directory. This file can be located here <code>app/Http/Middleware/JwtMiddleware</code>. Open up the file and replace the content with the following:</p>
<div class="language-php vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">php</span><pre class="vp-code" tabindex="0" v-pre><code>&lt;?php
namespace App\Http\Middleware;
use Closure;
use JWTAuth;
use Exception;
use Tymon\JWTAuth\Http\Middleware\BaseMiddleware;
class JwtMiddleware extends BaseMiddleware
{
  /**
   * Handle an incoming request. * * @param  \Illuminate\Http\Request  $request * @param  \Closure  $next * @return mixed
   */
  public function handle($request, Closure $next)
  {
    try {
      $user = JWTAuth::parseToken()-&gt;authenticate();
    }
    catch (Exception $e) {
      if ($e instanceof \Tymon\JWTAuth\Exceptions\TokenInvalidException) {
        return response()-&gt;json(['status' =&gt; 'Token is Invalid']);
      }
      else if ($e instanceof \Tymon\JWTAuth\Exceptions\TokenExpiredException) {
        return response()-&gt;json(['status' =&gt; 'Token is Expired']);
      }
      else {
        return response()-&gt;json(['status' =&gt; 'Authorization Token not found']);
      }
    }
    return $next($request);
  }
}</code></pre></div>
<p>This middleware extends <code>Tymon\JWTAuth\Http\Middleware\BaseMiddleware</code>, with this, we can catch token errors and return appropriate error codes to our users.</p>
<p>Next, we need to register our middleware. Open <code>app/http/Kernel.php</code> and add the following:</p>
<div class="language-php vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">php</span><pre class="vp-code" tabindex="0" v-pre><code>[...]
protected $routeMiddleware = [ [...]
  'jwt.verify' =&gt; \App\Http\Middleware\JwtMiddleware::class];
  [...]</code></pre></div>
