# PHP注释规范（PHPDOC）总结

<blockquote>
<p>针对PHP开发规范&#xff0c;有必要总结一下&#xff0c;与各位分享</p>
</blockquote>
<p>用过IDE或看过其他源码的小伙伴们应该都见过类似下面这样的注释</p>
<div class="language-php vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">php</span><pre class="vp-code" tabindex="0" v-pre><code>/**
 * 递归获取所有游戏分类 * @param int $id * @return array
 */</code></pre></div>
<p>看得多了就大概知道了一些规律。为了使自己的代码更加规zhuang范bi&#xff0c;也开始有样学样地写着这些注释。其实这种注释格式是有自己的名字的&#xff0c;它就叫——<strong>PHPDOC</strong>。</p>
<h2><a></a>1、介绍</h2>
<blockquote>
<p><strong>PHPDoc</strong> 是一个 PHP 版的 Javadoc。它是<strong>一种注释 PHP 代码的正式标准</strong>。它支持通过类似 phpDocumentor<br /> 这样的外部文档生成器生成 API 文档&#xff0c;也可以帮助一些例如 Zend Studio, NetBeans, ActiveState<br /> Komodo Edit and IDE 和 Aptana Studio 之类的 集成开发环境<br /> 理解变量类型和弱类型语言中的其他歧义并提供改进的代码完成&#xff0c;类型提示和除错功能。</p>
<p>PHPDoc 可 <strong>同时支持 面向对象</strong> 的和 <strong>面向过程</strong> 的 代码。</p>
</blockquote>
<p>简单来说<code>PHPDOC</code>可以用来自动生成API文档。主流的IDE都会识别它&#xff0c;并在你coding中给予你相应的智能提示。使用PHPDOC有以下好处 &#xff1a;</p>
<ul>
<li>让你的代码更加规zhuang范bi&#xff0c;更易于理解</li>
<li>让你的IDE更懂你的代码&#xff0c;更加智能的提示和自动完成</li>
<li>如需API手册&#xff0c;可使用 <code>phpDocumentor</code> 来自动生成</li>
</ul>
<h2><a></a>2、常规使用</h2>
<blockquote>
<p>有关phpDoc的完整文档位于<a href="https://www.phpdoc.org/docs/latest/index.html" rel="nofollow">phpDocumentor</a>官网。以下仅为整理的常用规范。</p>
</blockquote>
<hr />
<p><strong>&#64;api</strong><br /> 表示这是一个提供给第三方使用的API接口</p>
<hr />
<p><strong>&#64;author</strong><br /> 作者<br /> 格式<code>&#64;author [名称] [&lt;邮箱&gt;]</code><br /> 例如<code>&#64;author Leroi &lt;leroiliu&#64;163.com&gt;</code></p>
<hr />
<p><strong>&#64;copyright</strong><br /> 版权声明。例如很多网站底部都有<br /> 格式<code>&#64;copyright [描述]</code><br /> 例如<code>&#64;copyright 1949-2019 China</code></p>
<hr />
<p><strong>&#64;deprecated</strong><br /> 不建议使用的、已过期的、将被删除的<br /> 格式<code>&#64;deprecated [&lt;版本号&gt;] [&lt;描述&gt;]</code><br /> 例如<code>&#64;deprecated 1.0.0 新版本将不再包含此函数</code><br /> 如果它是被其他方法所取代了&#xff0c;建议添加<code>&#64;see</code>标记</p>
<hr />
<p><strong>&#64;example</strong><br /> 例子、示例、用例。也可表示方法返回值的例子<br /> 格式<code>&#64;example [位置] [&lt;起始行号&gt; [&lt;行数&gt;] ] [&lt;描述&gt;]</code><br /> 例如<code>&#64;example demo.php 10 3 使用示例</code></p>
<hr />
<p><strong>&#64;global</strong><br /> 全局变量<br /> 格式<code>&#64;global [类型][名称][描述]</code><br /> 类型<code>&#64;global string name 用户名</code></p>
<hr />
<p><strong>&#64;ignore</strong><br /> 忽略<br /> 格式<code>&#64;ignore [&lt;描述&gt;]</code><br /> 例如你在if和else的语句块中定义分别同一个变量但值不同时&#xff0c;可以通过此标记让<code>phpDocumentor</code>忽略其中一个&#xff0c;以免生成重复的文档。例如</p>
<div class="language-php vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">php</span><pre class="vp-code" tabindex="0" v-pre><code>if ($ostest) {
  /**
   * This define will either be 'Unix' or 'Windows'
   */
  define("OS", "Unix");
}
else {
  /**
   * @ignore
   */
  define("OS", "Windows");
}</code></pre></div>
<hr />
<p><strong>&#64;internal</strong><br /> 仅限内部使用的<br /> 格式<code>&#64;internal [描述]</code><br /> 例如<code>&#64;internal 仅限内部测试使用</code></p>
<hr />
<p><strong>&#64;license</strong><br /> 协议&#xff0c;很常见的啦<br /> 格式<code>&#64;license [&lt;url&gt;] [名称]</code><br /> 例如<code>&#64;license GPL</code></p>
<hr />
<p><strong>&#64;link</strong><br /> 链接&#xff0c;可用于辅助说明、引用文档等<br /> 格式<code>&#64;link [url] [&lt;描述&gt;]</code><br /> 例如&#64;link <a href="https://www.google.com/" rel="nofollow">https://www.google.com/</a> 谷歌</p>
<hr />
<p><strong>&#64;method</strong><br /> 方法。这是用在类注释里的标记。特别适合一些动态加载的类&#xff0c;<code>IDE</code>无法自动提示出来&#xff0c;这时就可以通过写<code>&#64;method</code>标记来告诉<code>IDE</code>我这类里有哪些方法<br /> 格式<code>&#64;method [返回值类型] [名称]([[类型] [参数]&lt;, ...&gt;]) [&lt;描述&gt;]</code><br /> 静态方法格式<code>&#64;method static [返回值类型] [名称]([[类型] [参数]&lt;, ...&gt;]) [&lt;描述&gt;]</code><br /> 例如<code>&#64;method string google(string $question) 向谷歌提问&#xff0c;返回答案内容</code></p>
<hr />
<p><strong>&#64;package</strong><br /> 包。但php没有包&#xff0c;所以就用来表示命名空间<br /> 例如<code>&#64;package yii\base\db</code></p>
<hr />
<p><strong>&#64;param</strong><br /> 参数&#xff0c;用于函数和方法注释里的标记<br /> 格式<code>&#64;param [Type] [name] [&lt;description&gt;]</code><br /> 例如<code>&#64;param string title 文章标题</code></p>
<hr />
<p><strong>&#64;property</strong><br /> 类属性&#xff0c;与<code>&#64;method</code>类似&#xff0c;可以告诉IDE我这类里有哪些属性<br /> 格式<code>&#64;property [Type] [name] [&lt;description&gt;]</code><br /> 例如<code>&#64;property int id 用户id</code></p>
<hr />
<p><strong>&#64;property-read</strong><br /> 只读的属性。例如<code>__get</code>魔术方法能够取到的属性<br /> 格式<code>&#64;property-read [Type] [name] [&lt;description&gt;]</code><br /> 例如<code>&#64;property-read int id 用户id</code></p>
<hr />
<p><strong>&#64;property-write</strong><br /> 只可写的属性。例如<code>__set</code>魔术方法能够设置的属性<br /> 格式<code>&#64;property-write [Type] [name] [&lt;description&gt;]</code><br /> 例如<code>&#64;property-write string name 用户名</code></p>
<hr />
<p><strong>&#64;return</strong><br /> 返回值<br /> 格式<code>&#64;return [类型] [&lt;描述&gt;]]</code><br /> 例如<code>&#64;return array 结果数组</code></p>
<hr />
<p><strong>&#64;see</strong><br /> 关联说明&#xff0c;类似<code>&#64;link</code>&#xff0c;可与<code>&#64;deprecated</code>联动<br /> 格式<code>&#64;see [url或完整方法名] [&lt;描述&gt;]</code><br /> 例如<code>&#64;see \yii\base\db::tableName() 旧方法table_name已弃用&#xff0c;请使用此方法替代</code></p>
<hr />
<p><strong>&#64;since</strong><br /> 从xx版本开始。例如从1.0之后添加了xx功能、删除了xx参数等<br /> 格式<code>&#64;since [1.0.0] [&lt;描述&gt;]</code><br /> 例如<code>&#64;since 1.0.2 添加了$b参数</code></p>
<hr />
<p><strong>&#64;throws</strong><br /> 可能会抛出的错误类型<br /> 格式<code>&#64;throws [类型] [&lt;描述&gt;]</code><br /> 例如<code>&#64;throws LifeException 没钱了&#xff0c;好想死啊</code></p>
<hr />
<p><strong>&#64;todo</strong><br /> 待办。提示自己或他人还需要做些什么<br /> 格式<code>&#64;todo [描述]</code><br /> 例如<code>&#64;todo 这个类还没做异常处理</code></p>
<hr />
<p><strong>&#64;uses</strong><br /> 使用<br /> 格式<code>&#64;uses [完整方法名] [&lt;描述&gt;]</code><br /> 例如<code>&#64;uses \yii\base\db::$count 使用此属性计数</code></p>
<hr />
<p><strong>&#64;var</strong><br /> 变量<br /> 格式<code>&#64;var [类型] [变量名] [&lt;描述&gt;]</code><br /> 例如<code>&#64;var int id 用户id</code></p>
<hr />
<p><strong>&#64;version</strong><br /> 版本号<br /> 格式<code>&#64;version [&lt;载体&gt;] [&lt;描述&gt;]</code><br /> 例如<code>&#64;version 1.0.1 2016-07-03更新</code><br /> 或者<code>&#64;version GIT:1f3197d01 来自GIT分支1f3197d01</code></p>
</div>
