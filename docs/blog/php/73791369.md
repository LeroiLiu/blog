# php类的封装、继承和多态的简单理解

面象对向的三大特点&#xff1a;封装性、继承性、多态性 首先简单理解一下抽象&#xff1a;<br />
<p>我们在前面定义一个类的时候&#xff0c;实际上就是把一类事物共有的属性和行为提取出来&#xff0c;形成一个物理模型&#xff08;模版&#xff09;&#xff0c;这种研究问题的方法称为抽象</p>
<h2>封装性 <br />
</h2>
<div>封装就是把抽取出来的数据和对数据的操作封装在一起&#xff0c;数据被保护在内部&#xff0c;程序的其他部分只有被授权的操作&#xff08;方法&#xff09;才能对数据进行操作。 <br />
php提供了三种访问控制修饰符 <br />
<span>public 表示全局&#xff0c;本类内部&#xff0c;类外部&#xff0c;子类都可以访问 <br />
protected 表示受保护的&#xff0c;只有本类或子类可以访问 <br />
private 表示私有的&#xff0c;只有本类内部可以访问 </span><br />
以上三种修饰符既可以修饰方法也可以修饰属性&#xff08;变量&#xff09;&#xff0c;方法如果没有访问修饰符则默认是public&#xff0c;成员属性必须指定访问修饰符&#xff0c;在PHP4中也有这种写法 var <code>$name</code>&#xff0c;表示公开属性&#xff0c;不推荐这种写法 <br />
例&#xff1a;<div class="language-php vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">php</span><pre class="vp-code" tabindex="0" v-pre><code>&lt;?php
class Person
{
  public $name;
  protected $age;
  private $salary;
  function __construct($name, $age, $salary)
  {
    $this-&gt;name = $name;
    $this-&gt;age = $age;
    $this-&gt;salary = $salary;
  }
  public function showinfo()
  {
    //这表示三个修饰符都可以在本类内部使用
    echo $this-&gt;name."||".$this-&gt;age."||".$this-&gt;salary;
  }
}
$p1 = new Person('张三', 20, 3000);
//这里属于类外部，那么如果用下面的方法访问age和salary都会报错 // echo $p1-&gt;age;
echo$p1-&gt;salary;
?&gt;</code></pre></div>那么现在就想在外部访问protected和private的元素和方法该怎么办&#xff1f; 通常做法是通过public函数去访问这些变量 格式&#xff1a; </div>
<div><div class="language-php vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">php</span><pre class="vp-code" tabindex="0" v-pre><code>public function setxxxx($val)
{
  $this-&gt;xxxx = $val;
}
public function getxxxx()
{
  return $this-&gt;xxxx;
}</code></pre></div>这里带<span>set和get只是为了识别方便&#xff0c;并非必要 </span><br />
如&#xff1a;<div class="language-php vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">php</span><pre class="vp-code" tabindex="0" v-pre><code>public function getsalary()
{
  return $this-&gt;salary;
  //扩展：这里可以调用一些方法，如判断用户名等，正确才给访问
}</code></pre></div>在外部就可以通过 echo $p1-&gt;getsalary(); <br />
如果要访问 protected和private也可以使用以下方法&#xff0c;但不推荐使用&#xff0c;只要了解即可 <br />
<code>__set() 和 __get()</code> <br />
<code>__set()</code>对protected或private属性进行赋值操作 <br />
<code>__set($pro_name, $pro_val)</code>; <br />
<code>__get()</code>获取 protected 或 private的值 <br />
<code>__get($pro_name)</code>; <br />
如&#xff1a;<br />
<div class="language-php vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">php</span><pre class="vp-code" tabindex="0" v-pre><code>&lt;?php
class testa
{
  protected $name;
  //使用__set()来管理所有属性
  public function __set($pro_name, $pro_val)
  {
    //上面$pro_name和$pro_val可自定义 //下面$this-&gt;pro_name为既定，不可更改
    $this-&gt;pro_name = $pro_val;
  }
  //使用__get()来获取所有属性值
  public function __get($pro_name)
  {
    if (isset($pro_name)) {
      return $this-&gt;pro_name;
    }
    else {
      return null;
    }
  }
}
$n1 = new testa();
//正常情况，类外部是不能访问protected属性的，但是用了上面的方法就可以对它们进行操作
$n1-&gt;name = '小三';
echo $n1-&gt;name;
//以上代码看懂就行，不推荐使用
?&gt;</code></pre></div>
<h2>继承性<br />
</h2>
<div>先看一个例子: <br />
</div>
<div><div class="language-php vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">php</span><pre class="vp-code" tabindex="0" v-pre><code>&lt;?php
class Pupil
{
  public $name;
  protected $age;
  public function getinfo()
  {
    echo $this-&gt;name.'||'.$this-&gt;age;
  }
  public function testing()
  {
    echo 'this is pupil';
  }
}
class Graduate
{
  public $name;
  protected $age;
  public function getinfo()
  {
    echo $this-&gt;name.'||'.$this-&gt;age;
  }
  public function testing()
  {
    echo 'this is Graduate';
  }
}
?&gt;</code></pre></div>从上面的例子可以看出&#xff0c;当多个类有很多共同属性和方法时&#xff0c;代码的复用性不高&#xff0c;代码冗余&#xff0c;思考css中的处理方法 <br />
解决方法 &#xff1a;继承 </div>
<div><div class="language-php vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">php</span><pre class="vp-code" tabindex="0" v-pre><code>&lt;?php
class Students
{
  public $name;
  public $age;
  public function __construct($name, $age)
  {
    $this-&gt;name = $name;
    $this-&gt;age = $age;
  }
  public function showinfo()
  {
    echo $this-&gt;name.'||'.$this-&gt;age;
  }
}
class Pupil extends Students
{
  function testing()
  {
    echo 'Pupil '.$this-&gt;name.' is testing';
  }
}
class Graduate extends Students
{
  function testing()
  {
    echo 'Graduate '.$this-&gt;name.' is testing';
  }
}
$stu1 = new Pupil('张三', 20);
$stu1-&gt;showinfo();
echo '&lt;br/&gt;';
$stu1-&gt;testing();
?&gt;</code></pre></div>
<div>从上面可以看出&#xff0c;继承就是一个子类(Subclass)通过 extends 父类 把父类(BaseClass)中的public 和 protected 的属性和方法继续下来&#xff0c;不能继承private属性和方法 <br />
语法结构&#xff1a; <br />
</div>
<div class="language-php vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">php</span><pre class="vp-code" tabindex="0" v-pre><code>class 父类名
{
}
class 子类名 extends 父类名
{
}</code></pre></div>细节&#xff1a; <br />
1、<span>一个子类只能继承一个父类&#xff08;这里指直接继承&#xff09;&#xff1b;如果希望继承多个类的属性和方法&#xff0c;可以使用多层继承 </span><br />
例&#xff1a; <div class="language-php vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">php</span><pre class="vp-code" tabindex="0" v-pre><code>&lt;?php
class A
{
  public $name = 'AAA';
}
class B extends A
{
  public $age = 30;
}
class C extends B
{
}
$p = new C();
echo $p-&gt;name;
//这里会输出AAA
?&gt;</code></pre></div>2、<span>在创建某个子类对象时&#xff0c;默认情况下不会自动调用其父类的构造函数 </span><br />
例&#xff1a; <div class="language-php vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">php</span><pre class="vp-code" tabindex="0" v-pre><code>class A
{
  public function __construct()
  {
    echo 'A';
  }
}
class B extends A
{
  public function __construct()
  {
    echo 'B';
  }
}
$b = new B();
//这里会优先输出B中的构造方法，如果B中没有构造方法才会输出A中的</code></pre></div>3、<span>在子类中如果需要访问父类的方法&#xff08;构造方法、成员方法 方法的修饰符为protected或private&#xff09;&#xff0c;那么可以使用 父类::方法名 或者 parent::方法名 来完成【这里parent和以前提到的self都均为小写&#xff0c;大写报错】</span></div>
<div><div class="language-php vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">php</span><pre class="vp-code" tabindex="0" v-pre><code>class A
{
  public function test()
  {
    echo 'a_test';
  }
}
class B extends A
{
  public function __construct()
  {
    //两种方法都行
    A::test();
    parent::test();
  }
}
$b = new B();</code></pre></div>5、如果一个子类(派生类)的方法与父类的方法完全一样时(public&#xff0c;protected)&#xff0c;我们称为方法覆盖或方法重写&#xff08;override&#xff09;&#xff0c;看下面的多态性 </div>
<div>
<h2>多态性 <br />
</h2>
<div>例 &#xff1a;<div class="language-php vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">php</span><pre class="vp-code" tabindex="0" v-pre><code>&lt;?php
class Animal
{
  public $name;
  public $price;
  function cry()
  {
    echo 'i don\'t know';
  }
}
class Dog extends Animal
{
  //覆盖、重写
  function cry()
  {
    echo 'Wang Wang!';
    Animal::cry();
    //这里不会报错，能正确执行父类的cry();
  }
}
$dog1 = new Dog();
$dog1-&gt;cry();
?&gt;</code></pre></div>
<br />
小结&#xff1a; <br />
1、<span>当一个父类知道所有的子类都有一个方法&#xff0c;但是父类不能确定该方法如何写&#xff0c;可以让子类去覆盖它的方法,方法覆盖(重写)&#xff0c;必须要求子类的方法名和参数个数完全一致</span>
<br />
2、<span>如果子类要去调用父类的某个方法(<code>protected/public</code>)&#xff0c;可以使用 父类名::方法名 或者 parent::方法名 </span><br />
3、<span>在实现方法重写的时候&#xff0c;访问修饰符可以不一样&#xff0c;但是子类方法的访问权限必须大于等于父类方法的访问权限&#xff08;即不能缩小父类方法的访问权限&#xff09; </span><br />
如 父类public <code>function cry(){} 子类 protected function cry()</code>{} 则会报错 <br />
但是子类的访问权限可以放大&#xff0c;如&#xff1a; <br />
父类private <code>function cry(){} 子类 protected function cry()</code>{} 可以正确执行 <br />
<br />
</div>
<div>扩展&#xff1a; <br />
方法重载&#xff08;overload&#xff09; <br />
基本概念&#xff1a;函数名相同&#xff0c;但参数的个数或参数的类型不同&#xff0c;达到调用同一个函数&#xff0c;可以区分不同的函数 <br />
在PHP5中虽然也支持重载&#xff0c;但是和其它语言还是有很大区别的&#xff0c;php中不能定义多个同名函数 <br />
PHP5中提供了强大的“魔术”函数&#xff0c;使用这些魔术函数&#xff0c;我们可以做到函数重载&#xff0c; <br />
这里我们要到到 __call,当一个对象调一个方法时&#xff0c;而该方法不存在&#xff0c;则程序会自动调用__call <br />
【官方不推荐使用】 <br />
PHP中有以下几个魔术常量&#xff1a;<code>__LINE__</code> <code>__FILE__</code> <code>__DIR__</code> <code>__FUNCTION__</code> <code>__CLASS__</code> 等 <br />
例&#xff1a;<div class="language-php vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">php</span><pre class="vp-code" tabindex="0" v-pre><code>&lt;?php
class A
{
  function test1($p)
  {
    echo 'test1&lt;br/&gt;';
  }
  function test2($p)
  {
    echo 'test2&lt;br/&gt;';
  }
  function __call($method, $p)
  {
    //这里$p为数组，上面两个变量名可自定义
    if ($method == 'test') {
      if (count($p)==1) {
        $this-&gt;test1($p);
      }
      else if (count($p)==2) {
        $this-&gt;test2($p);
      }
    }
  }
}
$a = new A();
$a-&gt;test(5);
$a-&gt;test(3, 5);
?&gt;</code></pre></div></div>
