# PHP中的错误级别

<div class="migrated-article" v-pre>
<p><span>错误报告级别</span><span>&#xff1a;指定了在什么情况下&#xff0c;脚本代码中的错误&#xff08;这里的错误是广义的错误&#xff0c;包括</span><span><span><span><span><code>E_NOTICE</code>注意、</span></span></span><span><code>E_WARNING</code>警告、</span><span><code>E_ERROR</code>致命错误等&#xff09;会以错误报告的形式输出。</span></span></p>
<div><span><span>&#xff08;|或&#xff0c;&amp;与&#xff0c;~非&#xff09;</span></span></div>
<div><span><span><span>设置错误报告级别的方法&#xff1a;</span></span></span></div>
<div><span><span>1. 修改PHP的配置文件<code>php.ini</code></span></span></div>
<div>
这种方式设置<span>error_reporting后&#xff0c;重启web服务器&#xff0c;就会永久生效。</span></div>
<div>
这里以xampp集成软件包为例&#xff0c;打开<span>配置文件<code>php.ini</code>&#xff0c;查看错误报告级别error_reporting的默认值&#xff0c;如下&#xff1a;</span></div>
<div>
<div>error_reporting&#61;<code>E_ALL</code> &amp; ~<code>E_DEPRECATED</code> &amp; ~<code>E_STRICT</code></div>
</div>
<div>
意思是报告所有的错误&#xff0c;但除了<span><code>E_DEPRECATED</code>和<code>E_STRICT</code>这两种。</span></div>
<div>
将其修改为&#xff1a;</div>
<div>
<span><span>error_reporting&#61;<code>E_ALL</code> &amp;  ~<code>E_NOTICE</code></span></span><br />
</div>
<div>
<span>意思是报告所有的错误&#xff0c;但除了<code>E_NOTICE</code>这一种。这也是最常用的错误报告级别&#xff0c;它不会报告注意类&#xff08;如&#xff1a;使用了未定义的变量&#xff09;的错误。</span></div>
<div>
<span>保存&#xff0c;重启web服务器后生效。</span></div>
<div><span><span><span>2. 使用</span><span><code>error_reporting()</code>函数</span></span></span></div>
<div>
这种方式设置后&#xff0c;可以立即生效。但仅限于在当前脚本中的<span><code>error_reporting()</code>函数调用的后面区域。</span><br />

<div>
<div>
<div>
<div>
<div><span>int </span><span><span>error_reporting</span></span> ([ <span><span>int</span><code> $level</code></span> ]
 )</div>
<div>参数可以是整型或对应的常量标识符&#xff0c;推荐使用常量的形式。返回值为当前位置处起作用的错误报告级别的值&#xff08;整型值&#xff09;。</div>
<div>下面列举一些错误报告级别&#xff1a;</div>
