# PHP面向对象三大特性之封装基础

:::

<div class="migrated-article" v-pre>
<div>
<p>封装性是面象对象编程中的三大特性之一&#xff0c;封装性就是把对象的属性和服务结合成一个独立的相同单位&#xff0c;并尽可能隐蔽对象的内部细节&#xff0c;包含两个含义&#xff1a;</p>
<p>1. 把对象的全部属性和全部服务结合在一起&#xff0c;形成一个不可分割的独立单位&#xff08;即对象&#xff09;。</p>
<p>2. 信息隐蔽&#xff0c;即尽可能隐蔽对象的内部细节&#xff0c;对外形成一个边界〔或者说形成一道屏障〕&#xff0c;只保留有限的对外接口使之与外部发生联系。</p>
<p>封装的原则在软件上的反映是&#xff1a;要求使对象以外的部分不能随意存取对象的内部数据&#xff08;属性&#xff09;&#xff0c;从而有效的避免了外部错误对它的&#34;交叉感染&#34;&#xff0c;使软件错误能够局部化&#xff0c;大大减少查错和排错的难度。</p>
<p>用个实例来说明吧&#xff0c; 假如某个人的对象中有年龄和工资等属性&#xff0c;像这样个人隐私的属性是不想让其它人随意就能获得到的&#xff0c;如果你不使用封装&#xff0c;那么别人想知道就能得到&#xff0c;但是如果你封装上之后别人就没有办法获得封装的属性&#xff0c; 除非你自己把它说出去&#xff0c;否则别人没有办法得到。</p>
<p>在比如说&#xff0c;个人电脑都有一个密码&#xff0c;不想让其它人随意的登陆&#xff0c;在你电脑里面拷贝和粘贴。还有就是像人这个对象&#xff0c; 身高和年龄的属性&#xff0c; 只能是自己来增涨&#xff0c;不可以让别人随意的赋值等等。</p>
<p>使用private这个关键字来对属性和方法进行封装&#xff1a;</p>

<div class="language-php vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">php</span><pre class="vp-code" tabindex="0" v-pre><code>&lt;?php
class Person
{
  //下面是人的成员属性
  private$name;
  //人的名子, 被private封装上了
  private$sex;
  //人的性别, 被private封装上了
  private$age;
  //人的年龄, 被private封装上了
  //定义一个构造方法参数为私有的属性姓名$name、性别$sex和年龄$age进行赋值
  function __construct($name, $sex, $age)
  {
    //通过构造方法传进来的$name给私有成员属性$this-&gt;name赋初使值
    $this-&gt;name = $name;
    //通过构造方法传进来的$sex给私有成员属性$this-&gt;sex赋初使值
    $this-&gt;sex = $sex;
    //通过构造方法传进来的$age给私有成员属性$this-&gt;age赋初使值
    $this-&gt;age = $age;
  }
  //这个人可以说话的方法, 说出自己的私有属性, 在这里也可以访问私有方法
  function say()
  {
    echo"我的名子叫：" . $this-&gt;name . " 性别：" . $this-&gt;sex . " 我的年龄是：" . $this-&gt;age;
  }
}
//通过构造方法创建3个对象$p1、p2、$p3, 分别传入三个不同的实参为姓名、性别和年龄
$p1 = new Person("张三", "男", 20);
$p2 = new Person("李四", "女", 30);
$p3 = new Person("王五", "男", 40);
//下面访问$p1对象中的说话方法
$p1-&gt;say();
//下面访问$p2对象中的说话方法
$p2-&gt;say();
//下面访问$p3对象中的说话方法
$p3-&gt;say();
?&gt;</code></pre></div>
