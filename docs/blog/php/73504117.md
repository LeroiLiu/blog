<div class="migrated-article" v-pre>
<p>使用phpqrcode类库生成二维码这里我们只需要了解一个类库中的方法&#xff1a;</p>
<p>1、原型&#xff1a;</p>

<div class="language-php vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">php</span><pre class="vp-code" tabindex="0" v-pre><code>public static function png($text, $outfile = false, $level = QR_ECLEVEL_L, $size = 3, $margin = 4, $saveandprint = false, $back_color = 0xFFFFFF, $fore_color = 0x000000)
{
  $enc = QRencode::factory($level, $size, $margin, $back_color, $fore_color);
  return $enc-&gt;encodePNG($text, $outfile, $saveandprint = false);
}</code></pre></div>

2、参数解析&#xff1a;
<p><code>$text</code>表示生成二位的的信息文本&#xff1b;</p>
<p><code>$outfile</code>表示是否输出二维码图片文件&#xff0c;默认否&#xff1b;</p>
<p><code>$level</code>表示容错率&#xff0c;也就是有被覆盖的区域还能识别&#xff0c;分别是L&#xff08;QR_ECLEVEL_L&#xff0c;7%&#xff09;&#xff0c;M&#xff08;QR_ECLEVEL_M&#xff0c;15%&#xff09;&#xff0c;Q&#xff08;QR_ECLEVEL_Q&#xff0c;25%&#xff09;&#xff0c;H&#xff08;QR_ECLEVEL_H&#xff0c;30%&#xff09;&#xff1b;</p>
<p><code>$size</code>表示生成图片大小&#xff0c;默认是3&#xff1b;</p>
<p><code>$margin</code>表示二维码周围边框空白区域间距值&#xff1b;</p>
<p><code>$saveandprint</code>表示是否保存二维码并显示。<br />
<br />
</p>

<p>5、给二维码添加logo&#xff1a;</p>

<div class="language-php vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">php</span><pre class="vp-code" tabindex="0" v-pre><code>include 'phpqrcode.php';
$value = 'http://www.helloweba.com';
//二维码内容
$errorCorrectionLevel = 'L';
//容错级别
$matrixPointSize = 6;
//生成图片大小 //生成二维码图片
QRcode::png($value, 'qrcode.png', $errorCorrectionLevel, $matrixPointSize, 2);
$logo = 'logo.png';
//准备好的logo图片
$QR = 'qrcode.png';
//已经生成的原始二维码图
if ($logo !== FALSE) {
  $QR = imagecreatefromstring(file_get_contents($QR));
  $logo = imagecreatefromstring(file_get_contents($logo));
  $QR_width = imagesx($QR);
  //二维码图片宽度
  $QR_height = imagesy($QR);
  //二维码图片高度
  $logo_width = imagesx($logo);
  //logo图片宽度
  $logo_height = imagesy($logo);
  //logo图片高度
  $logo_qr_width = $QR_width / 5;
  $scale = $logo_width/$logo_qr_width;
  $logo_qr_height = $logo_height/$scale;
  $from_width = ($QR_width - $logo_qr_width) / 2;
  //重新组合图片并调整大小
  imagecopyresampled($QR, $logo, $from_width, $from_width, 0, 0, $logo_qr_width, $logo_qr_height, $logo_width, $logo_height);
}
//输出图片
imagepng($QR, 'helloweba.png');
echo '&lt;img src = "helloweba.png"&gt;';</code></pre></div>
