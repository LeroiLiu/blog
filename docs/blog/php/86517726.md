<h3><a></a>配置</h3>
<p>基本使用的可以情况下可用如下配置&#xff08;<code>/home/wwwroot/odin.com/odin/config/database.php</code>&#xff09;&#xff1a;</p>
<div class="language-php vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">php</span><pre class="vp-code" tabindex="0" v-pre><code>'redis' =&gt; [
  'client' =&gt; 'predis',
  'default' =&gt; [
    'host' =&gt; env('REDIS_HOST', '127.0.0.1'),
    'password' =&gt; env('REDIS_PASSWORD', null),
    'port' =&gt; env('REDIS_PORT', 6379),
    'database' =&gt; env('REDIS_DB', 0),
  ],
  'cache' =&gt; [
    'host' =&gt; env('REDIS_HOST', '127.0.0.1'),
    'password' =&gt; env('REDIS_PASSWORD', null),
    'port' =&gt; env('REDIS_PORT', 6379),
    'database' =&gt; env('REDIS_CACHE_DB', 1),
  ],
],</code></pre></div>
<p>当然&#xff0c;这里是基础配置&#xff0c;如果在<code>.env</code>中定义了变量&#xff0c;就要在<code>.env</code>中修改配置&#xff1a;</p>
<div class="language-text vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">text</span><pre class="vp-code" tabindex="0" v-pre><code>REDIS_HOST=127.0.0.1

<h3><a></a>常用方法</h3>
<h4><a></a>操作哈希</h4>
<div class="language-php vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">php</span><pre class="vp-code" tabindex="0" v-pre><code>//设置值
Redis::command('hset', ['table1', 'use1', 'token1']);
//redis读取哈希
Redis::command('hget', ['table1', 'use1']);
//检测是否存在key
Redis::command('hexists', ['table1', 'use2']);
//设置时间限制
Redis::expire('table1', 5);
//laravel 发布订阅
Redis::command('publish', ['key', json_encode(['foo' =&gt; 'bar'])]);
Redis::subscribe(['test-channel'], function ($message) {
  echo $message;
});</code></pre></div>
<h4><a></a>操作字符串</h4>
<div class="language-php vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">php</span><pre class="vp-code" tabindex="0" v-pre><code>//设置指定 key 的值
Redis::SET('name', 'Leroi');
//获取指定key的值
$name = Redis::GET('name');
//输出Leroi //返回 key 所储存的字符串值的长度
Redis::STRLEN('name');
//将 key 中储存的数字值增一
Redis::INCR('number');
//将 key 中储存的数字值减一
Redis::DECR('number');</code></pre></div>
<h4><a></a>操作列表</h4>
<div class="language-php vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">php</span><pre class="vp-code" tabindex="0" v-pre><code>//将一个值或多个值插入到列表头部（在列表左侧插入）
Redis::LPUSH('testList', 'list_left');
//在列表中添加一个值或多个值（在列表右侧插入）
Redis::RPUSH('testList', 'list_right');
//获取列表长度
Redis::LLEN('testList') //获取列表指定范围内的元素
Redis::LRANGE('testList', 0, -1);
//获取列表全部元素
Redis::LRANGE('testList', 0, 1);
//获取索引值0到1的元素 //移出并获取列表的第一个元素， 如果列表没有元素会阻塞列表直到等待超时或发现可弹出元素为止
Redis::BLPOP('testList', 10);
//如果没有元素, 会阻塞列表10秒钟, BRPOP同此 //通过索引获取列表中的元素（从列表表左侧开始计算, 索引从0开始）
Redis::LPUSH('testList', 1);
Redis::LPUSH('testList', 2);
$two = Redis::LINDEX('testList', 0);
//输出$two为2 //在列表中某一元素前面或者后面插入新的元素
Redis::LPUSH('testList', 1);
Redis::LPUSH('testList', 2);
Redis::LINSERT('testList', 'AFTER', 1, 3);
$list = Redis::LRANGE('testList', 0, -1);
//$list 输出为：2 1 3</code></pre></div>
