<h2>类中接口的应用</h2>
<div>1.关键字&#xff1a;interface<br />
2.关键字&#xff1a;implements<br />
</div>
<h3>1.接口的介绍与创建<br />
</h3>
<div><strong>接口&#xff1a;</strong><span>一种成员属性全部为抽象或常量的特殊抽象类。</span><br />
<strong>规则&#xff1a;</strong><br />
1.类中全部为抽象方法。<br />
2.抽象方法前不用加abstract。<br />
3.接口抽象方法属性为public。</div>
<div>4.<span>成员属性必须为常量</span>。<br />
<strong>格式代码如下:</strong><br />
</div>
<div><div class="language-php vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">php</span><pre class="vp-code" tabindex="0" v-pre><code>interface demo {
  const NAME = "常量对象属性";
  function fun1();
  function fun2();
  //抽象方法。
}</code></pre></div>
<h3>2.接口的应用与规范<br />
</h3>
<div><span>接口引用区别于类继承关键字 extends &#xff0c;继承只能只是单一性&#xff0c;而接口可以使用关键字 implements 多个引用并用逗号分开。</span><br />
</div>
<strong>1.格式&#xff1a;普通类引用接口</strong><br />
</div>
<div><div class="language-php vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">php</span><pre class="vp-code" tabindex="0" v-pre><code>class MyPc implements demo , demo2 , demo3
{
  ...
}</code></pre></div>
<strong>2.格式&#xff1a;抽象类应用接口例子</strong></div>
<div><div class="language-php vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">php</span><pre class="vp-code" tabindex="0" v-pre><code>abstract class MyPc implements demo , demo2 , demo3 {
  ...
}</code></pre></div>
<strong>3.格式&#xff1a;继承父类引用接口并存</strong></div>
<div><div class="language-php vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">php</span><pre class="vp-code" tabindex="0" v-pre><code>class MyPc extends Root implements demo , demo2 , demo3
{
  ...
}</code></pre></div>先继承后接口&#xff0c;单继承多接口。</div>
<div><strong>4.格式&#xff1a;接口与接口的继承</strong></div>
<div><div class="language-php vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">php</span><pre class="vp-code" tabindex="0" v-pre><code>interface demo3 extends demo {
  ...
}</code></pre></div>
<div>实例一&#xff1a;例,接口使用关键字 interface 来定义&#xff0c;并使用关键字 implements 来实现接口中的方法&#xff0c;且必须完全实现。</div>

<div class="language-php vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">php</span><pre class="vp-code" tabindex="0" v-pre><code>&lt;?php
//定义接口
interface User {
  function getDiscount();
  function getUserType();
}
//VIP用户 接口实现
class VipUser implements User
{
  // VIP 用户折扣系数
  private $discount = 0.8;
  function getDiscount()
  {
    return $this-&gt;discount;
  }
  function getUserType()
  {
    return "VIP用户";
  }
}
class Goods
{
  var $price = 100;
  var $vc;
  //定义 User 接口类型参数，这时并不知道是什么用户
  function run(User $vc)
  {
    $this-&gt;vc = $vc;
    $discount = $this-&gt;vc-&gt;getDiscount();
    $usertype = $this-&gt;vc-&gt;getUserType();
    echo $usertype."商品价格：".$this-&gt;price*$discount;
  }
}
$display = new Goods();
$display-&gt;run(new VipUser);
//可以是更多其他用户类型

<div><strong>实现多个接口</strong><br />
</div>
<div>PHP也可以在继承一个类的时候同时实现多个接口&#xff1a;<div class="language-php vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">php</span><pre class="vp-code" tabindex="0" v-pre><code>class 子类 extends 父类 implemtns 接口1, 接口2, ...
{
  ......
}</code></pre></div>
<span><strong><span>抽象类和接口的区别</span></strong></span><br />
接口是特殊的抽象类&#xff0c;也可以看做是一个模型的规范。接口与抽象类大致区别如下&#xff1a;<br />
1.<span>一个子类如果 implements 一个接口&#xff0c;就必须实现接口中的所有方法&#xff08;不管是否需要&#xff09;&#xff1b;如果是继承一个抽象类&#xff0c;只需要实现需要的方法即可</span>。<br />
2.<span>如果一个接口中定义的方法名改变了&#xff0c;那么所有实现此接口的子类需要同步更新方法名&#xff1b;而抽象类中如果方法名改变了&#xff0c;其子类对应的方法名将不受影响&#xff0c;只是变成了一个新的方法而已&#xff08;相对老的方法实现&#xff09;</span>。<br />
3.<span>抽象类只能单继承&#xff0c;当一个子类需要实现的功能需要继承自多个父类时&#xff0c;就必须使用接口</span>。<br />
<br />
</div>
