# abstract抽象类和abstract抽象方法

<div class="migrated-article" v-pre>
<p>
<span>抽象类里的方法可以有方法体&#xff0c;只有抽象方法才不能拥有方法体。接口中的方法一定为抽象方法没有方法体&#xff0c;抽象类中的抽象方法才有方法体&#xff0c;但并不全为抽象方法。接口中虽然全部都为抽象方法&#xff0c;不可以定义属性&#xff0c;但是也可以定义常量。</span></p>
<p> 可以使用abstract来修饰一个类或者方法。</p>
<p> 用abstract修饰的类表示这个类是一个抽象类&#xff0c;用abstract修饰的方法表示这个方法是一个抽象方法。</p>
<p> 抽象类不能被实例化。</p>
<p> 抽象方法是只有方法声明&#xff0c;而没有方法的实现内容。</p>
<h3>abstract 抽象类</h3>
<p> 可以使用abstract来修饰一个类。</p>
<p> 用abstract修饰的类表示这个类是一个抽象类。</p>
<p> 抽象类不能被实例化。</p>
<p> 这是一个简单抽象的方法&#xff0c;如果它被直接实例化&#xff0c;系统会报错。</p>

<p> 单独设置一个抽象类是没有意义的&#xff0c;只有有了抽象方法&#xff0c;抽象类才有了血肉。下面介绍抽象方法。</p>
<h3>abstract 抽象方法</h3>
<p> 用abstract修饰的类表示这个方法是一个抽象方法。</p>
<p> 抽象方法&#xff0c;只有方法的声明部分&#xff0c;没有方法体。</p>
<p> 抽象方法没有 {} &#xff0c;而采用 ; 结束。</p>
<p> 一个类中&#xff0c;只要有一个抽象方法&#xff0c;这个类必须被声明为抽象类。</p>
<p> 抽象方法在子类中必须被重写。</p>
<p> 下面是一个抽象类&#xff0c;其中有两个抽象方法&#xff0c;分别是 <code>setSal() 和 getSal()</code>。用来取回 <code>$sal</code> 员工的工资。</p>

<div>
<div>
<div>
<strong>[php]</strong>
</div>
</div>
<div class="language-php vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">php</span><pre class="vp-code" tabindex="0" v-pre><code>&lt;?php
abstract class User
{
  protected$sal = 0;
  //这里定义的抽象方法。
  //注意抽象方法没有方法体，而且方法结束使用 ;
  号。
  abstract function getSal();
  abstract function setSal();
  //定义它的__tostring方法
  public function __toString()
  {
    return get_class($this);
  }
}

<strong>抽象类继承抽象类</strong></p>
<p>

<p>
<span>抽象类中&#xff0c;不能重写抽象父类的抽象方法。</span></p>
<p> 这样的用法&#xff0c;可以理解为对抽象类的扩展</p>
<p> 下面的例子&#xff0c;演示了一个抽象类继承自另外一个抽象类时&#xff0c;不需要重写其中的抽象方法。</p>

<h3>静态抽象方法</h3>
<p> 在PHP5.1中&#xff0c;抽象类中支持静态抽象方法。下面这个例子&#xff0c;看到静态抽象方法可以声明。实现这个方法时&#xff0c;必须是静态的方法。</p>

<div>
<div>
<div>
<strong>[php]</strong>
</div>
</div>
<div class="language-php vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">php</span><pre class="vp-code" tabindex="0" v-pre><code>&lt;?php
abstract class User
{
  protectedstatic$sal = 0;
  static abstract function getSal();
  static abstract function setSal($sal);
}
class VipUser extends User
{
  static function getSal()
  {
    return self::$sal;
  }
  static function setSal($sal)
  {
    self::$sal = $sal;
  }
}
VipUser::setSal(100);
echo"you sal is " . VipUser::getSal();
?&gt;
//这里的抽象方法好像没有问题。</code></pre></div>
