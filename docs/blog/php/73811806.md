# PHP中的Trait 特性及作用

<div class="migrated-article" v-pre>
<p>Traits 是一种为类似 PHP 的单继承语言而准备的代码复用机制。Trait 为了减少单继承语言的限制&#xff0c;使开发人员能够自由地在不同层次结构内独立的类中复用方法集</p>
<p>自 PHP 5.4.0 起&#xff0c;PHP 实现了代码复用的一个方法&#xff0c;称为 traits。<br />
Traits 是一种为类似 PHP 的单继承语言而准备的代码复用机制。Trait 为了减少单继承语言的限制&#xff0c;使开发人员能够自由地在不同层次结构内独立的类中复用方法集。Traits 和类组合的语义是定义了一种方式来减少复杂性&#xff0c;避免传统多继承和混入类&#xff08;Mixin&#xff09;相关的典型问题。<br />
Trait 和一个类相似&#xff0c;但仅仅旨在用细粒度和一致的方式来组合功能。Trait 不能通过它自身来实例化。它为传统继承增加了水平特性的组合&#xff1b;也就是说&#xff0c;应用类的成员不需要继承。<br />
Trait是在PHP5.4中加入的&#xff0c;它既不是接口也不是类。主要是为了解决单继承语言的限制。是PHP多重继承的一种解决方案。例如&#xff0c;需要同时继承两个 Abstract Class&#xff0c; 这将会是件很麻烦的事情&#xff0c;Trait 就是为了解决这个问题。它能被加入到一个或多个已经存在的类中。它声明了类能做什么&#xff08;表明了其接口特性&#xff09;&#xff0c;同时也包含了具体实现&#xff08;表明了其类特性&#xff09;<br />
</p>
<h2>简单使用<br />
</h2>
<div>首先&#xff0c;当然是声明个 Trait&#xff0c;PHP5.4 增加了 trait 关键字&#xff1a;<br />
</div>
<div><div class="language-php vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">php</span><pre class="vp-code" tabindex="0" v-pre><code>trait first_trait {
  function first_method()
  {
    /* Code Here
     */
  }
  function second_method()
  {
    /* Code Here
     */
  }
}</code></pre></div>同时&#xff0c;如果要在 Class 中使用该 Trait&#xff0c;那么使用 use 关键字&#xff1a;</div>
<div><div class="language-php vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">php</span><pre class="vp-code" tabindex="0" v-pre><code>class first_class
{
  // 注意这行，声明使用 first_trait
  use first_trait;
}
$obj = new first_class();
// Executing the method from trait
$obj-&gt;first_method();
// valid
$obj-&gt;second_method();
// valid</code></pre></div>
<h2>使用多个 Trait</h2>
<div>在同个 Class 中可以使用多个 Trait&#xff1a;<br />
</div>
<div><div class="language-php vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">php</span><pre class="vp-code" tabindex="0" v-pre><code>trait first_trait
{
  function first_method()
  {
    echo "method";
  }
}
trait second_trait {
  function second_method()
  {
    echo "method";
  }
}
class first_class
{
  // now using more than one trait
  use first_trait, second_trait;
}
$obj = new first_class();
// Valid
$obj-&gt;first_method();
// Print : method // Valid
$obj-&gt;second_method();
// Print : method</code></pre></div>
<br />
</div>
<h2>Trait 之间的嵌套<br />
</h2>
<div>同时&#xff0c;Trait 之间也可以相互的嵌套&#xff0c;例如&#xff1a;<br />
</div>
<div><div class="language-php vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">php</span><pre class="vp-code" tabindex="0" v-pre><code>trait first_trait {
  function first_method()
  {
    echo "method";
  }
}
trait second_trait {
  use first_trait;
  function second_method()
  {
    echo "method";
  }
}
class first_class
{
  // now using
  use second_trait;
}
$obj = new first_class();
// Valid
$obj-&gt;first_method();
// Print : method // Valid
$obj-&gt;second_method();
// Print : method</code></pre></div>

<h2>Trait 的抽象方法&#xff08;Abstract Method&#xff09;<br />
</h2>
</div>
<div>我们可以在 Trait 中声明需要实现的抽象方法&#xff0c;这样能使使用它的 Class 必须实现它&#xff1a;<br />
</div>
<div><div class="language-php vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">php</span><pre class="vp-code" tabindex="0" v-pre><code>trait first_trait {
  function first_method()
  {
    echo "method";
  }
  // 这里可以加入修饰符，说明调用类必须实现它
  abstract public function second_method();
}
class first_method
{
  use first_trait;
  function second_method()
  {
    /* Code Here
     */
  }
}</code></pre></div>
<h2>Trait 冲突<br />
</h2>
<div>多个 Trait 之间同时使用难免会冲突&#xff0c;这需要我们去解决。PHP5.4 从语法方面带入了相关 的关键字语法&#xff1a;insteadof 以及 as &#xff0c;用法参见&#xff1a;<br />
</div>
<div><div class="language-php vp-adaptive-theme"><button title="Copy Code" class="copy"></button><span class="lang">php</span><pre class="vp-code" tabindex="0" v-pre><code>trait first_trait {
  function first_function()
  {
    echo "From First Trait";
  }
}
trait second_trait {
  // 这里的名称和 first_trait 一样，会有冲突
  function first_function()
  {
    echo "From Second Trait";
  }
}
class first_class
{
  use first_trait, second_trait {
    // 在这里声明使用 first_trait 的 first_function 替换 // second_trait 中声明的
    first_trait::first_function insteadof second_trait;
  }
}
$obj = new first_class();
// Output: From First Trait
$obj-&gt;first_function();</code></pre></div>
上面就是些 Trait 比较基本的使用了&#xff0c;更详细的可以查看官方手册。这里总结下注意的几 点&#xff1a;<br />
<span>Trait 会覆盖调用类继承的父类方法<br />
Trait 无法如 Class 一样使用 new 实例化<br />
单个 Trait 可由多个 Trait 组成<br />
在单个 Class 中&#xff0c;可以使用多个 Trait<br />
Trait 支持修饰词&#xff08;modifiers&#xff09;&#xff0c;例如 final、static、abstract<br />
我们能使用 insteadof 以及 as 操作符解决 Trait 之间的冲突</span><br />
</div>
