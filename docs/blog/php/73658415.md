# PHP包含文件函数include、include_once、require、require_once的使用

<p>话不多说&#xff0c;直接上干货&#xff1a;</p>
<p>区别一&#xff1a;</p>
<p><span>1、<code>include()</code><span>遇到包含文件不存在&#xff0c;或是出错的时候&#xff0c;不停止运行&#xff0c;并报错。</span></span><br />
<span>2、<code>require()</code> </span><span>遇到包含文件不存在&#xff0c;或是出错的时候&#xff0c;就停止运行&#xff0c;并报错。</span></p>
<p><span><span>举例&#xff1a;</span></span></p>

<p>区别三&#xff1a;</p>
<p><span><code>include_once() 和require_once()</code>语句均在脚本执行期间包含并运行指定文件。此行为分别与<code>include() require()</code> 语句类似&#xff0c;</span></p>
<p><span>唯一区别是<span><code>include_once()</code> 和</span><span><code>require_once()</code></span>会先判断一下这个文件在之前是否已经被包含过&#xff0c;如已经包含&#xff0c;则忽略本次包含。</span></p>
<p><span><span><code>include_once()</code> 和</span><span><code>require_once()</code></span>
 应该用于嵌套包含的情况下&#xff0c;想确保它只被包含一次以避免函数重定义&#xff0c;变量重新赋值等问题。</span><br />
</p>
<p class="article-result"><span>注意&#xff1a;随着网站越来越大&#xff0c;可能会出现重复包含某些文件。这也许不是问题&#xff0c;但又是修改了所包含文件的变量后&#xff0c;却由于后面再次包含原来的文件而被覆盖&#xff0c;可能不希望出现这种情况。还可能出现另一个问题&#xff0c;即所包含文件中函数名的冲突。使用<span><code>include_once()</code>
 和</span><span><code>require_once()</code></span>就可以解决这些问题。<br />
</span></p>
<p><span>区别四&#xff1a;</span></p>
<p><span><code>include_once(),require_once(),与include(),require()</code>比较&#xff0c;效率要低一些&#xff0c;因为他们至少得先判断一下这个文件是否已包含。</span></p>
