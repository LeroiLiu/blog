<h2>
1、连接Mysql</h2>
<div>
格式&#xff1a; <code>mysql -h主机地址 -u用户名 &#xff0d;p用户密码</code><br />
<br />
<strong>1、连接到本机上的MYSQL。</strong><br />
首先打开DOS窗口&#xff0c;然后进入目录mysql\bin&#xff0c;再键入命令<code>mysql -u root -p&#xff0c;回车后提示你输密码.注意用户名前可以有空格也可以没有空格&#xff0c;但是密码前必须没有空格&#xff0c;否则让你重新输入密码</code>。<br />
<br />
如果刚安装好MYSQL&#xff0c;超级用户root是没有密码的&#xff0c;故直接回车即可进入到MYSQL中了&#xff0c;MYSQL的提示符是&#xff1a; mysql&gt;<br />
<br />
<strong>2、连接到远程主机上的MYSQL。</strong>假设远程主机的IP为&#xff1a;110.110.110.110&#xff0c;用户名为root,密码为abcd123。则键入以下命令&#xff1a;<br />
    <code>mysql -h110.110.110.110 -u root -p 123;&#xff08;注:u与root之间可以不用加空格&#xff0c;其它也一样&#xff09;</code><br />
<br />
<strong>3、退出MYSQL命令</strong>&#xff1a; exit &#xff08;回车&#xff09;</div>
<h2>2、修改密码</h2>
<div>
格式&#xff1a;mysqladmin -u用户名 -p旧密码 password 新密码<br />
<br />
<strong>1、给root加个密码ab12。</strong><br />
首先在DOS下进入目录mysql\bin&#xff0c;然后键入以下命令<br />
    mysqladmin <code>-u</code> root <code>-password</code> ab12<br />
注&#xff1a;因为开始时root没有密码&#xff0c;所以-p旧密码一项就可以省略了。<br />
<br />
<strong>2、再将root的密码改为djg345。</strong><br />
    mysqladmin <code>-u</code> root <code>-p</code> ab12 password djg345</div>
<h2>3、增加新用户</h2>
<div class="article-result">
注意&#xff1a;和上面不同&#xff0c;下面的因为是MYSQL环境中的命令&#xff0c;所以后面都带一个分号作为命令结束符<br />
<br />
格式&#xff1a;grant select on 数据库.* to 用户名&#64;登录主机 identified by “密码”<br />
<br />
<strong>1、增加一个用户test1密码为abc&#xff0c;让他可以在任何主机上登录&#xff0c;并对所有数据库有查询、插入、修改、删除的权限。首先用root用户连入MYSQL&#xff0c;然后键入以下命令&#xff1a;</strong><br />
    grant select,insert,update,<code>delete</code> on *.* to [email&#61;test1&#64;”%]test1&#64;”%[/email]” Identified by “abc”;<br />
<br />
但增加的用户是十分危险的&#xff0c;你想如某个人知道test1的密码&#xff0c;那么他就可以在internet上的任何一台电脑上登录你的mysql数据库并对你的数据可以为所欲为了&#xff0c;解决办法见2。<br />
<br />
<strong>2、增加一个用户test2密码为abc,让他只可以在localhost上登录&#xff0c;并可以对数据库mydb进行查询、插入、修改、删除的操作&#xff08;localhost指本地主机&#xff0c;即MYSQL数据库所在的那台主机&#xff09;</strong>&#xff0c;这样用户即使用知道test2的密码&#xff0c;他也无法从internet上直接访问数据库&#xff0c;只能通过MYSQL主机上的web页来访问了。<br />
    grant select,insert,update,<code>delete</code> on mydb.* to [email&#61;test2&#64;localhost]test2&#64;localhost[/email] identified by “abc”;<br />
<br />
如果你不想test2有密码&#xff0c;可以再打一个命令将密码消掉。<br />
    grant select,insert,update,<code>delete</code> on mydb.* to [email&#61;test2&#64;localhost]test2&#64;localhost[/email] identified by “”;</div>
<h2>4.1 创建数据库</h2>
<div class="article-note">
注意&#xff1a;创建数据库之前要先连接Mysql服务器<br />
<br />
命令&#xff1a;create database &lt;数据库名&gt;<br />
<br />
<strong>例1&#xff1a;建立一个名为xhkdb的数据库</strong><br />
   mysql&gt; create database xhkdb;<br />
<br />
<strong>例2&#xff1a;创建数据库并分配用户</strong><br />

①CREATE DATABASE 数据库名;<br />
<br />
②GRANT SELECT,INSERT,UPDATE,DELETE,CREATE,DROP,ALTER ON 数据库名.* TO 数据库名&#64;localhost IDENTIFIED BY &#39;密码&#39;;<br />
<br />
③SET PASSWORD FOR &#39;数据库名&#39;&#64;&#39;localhost&#39; &#61; <code>OLD_PASSWORD(&#39;密码&#39;)</code>;<br />
<br />
依次执行3个命令完成数据库创建。注意&#xff1a;中文 “密码”和“数据库”是户自己需要设置的。</div>

<br />
<strong>1、修改MYSQL的配置文件&#xff1a;</strong><code>my.ini</code>里面修改default-character-set&#61;gbk<br />

   ①Java代码&#xff1a;jdbc:mysql://localhost:3306/test?useUnicode&#61;true&amp;characterEncoding&#61;gbk<br />
   ②PHP代码&#xff1a;<code>header(&#34;Content-Type:text/html;charset&#61;gb2312&#34;)</code>;<br />
   ③C语言代码&#xff1a;<code>int mysql_set_character_set( MYSQL * mysql, char * csname)</code>&#xff1b;<br />
该函数用于为当前连接设置默认的字符集。字符串csname指定了1个有效的字符集名称。连接校对成为字符集的默认校对。该函数的工作方式与SET NAMES语句类似&#xff0c;但它还能设置mysql- &gt; charset的值&#xff0c;从而影响了由<code>mysql_real_escape_string()</code> 设置的字符集。</div>

<h2>4.4 连接数据库</h2>
<div>
命令&#xff1a; use &lt;数据库名&gt;<br />
<br />
例如&#xff1a;如果xhkdb数据库存在&#xff0c;尝试存取它&#xff1a;<br />
   mysql&gt; use xhkdb;<br />
屏幕提示&#xff1a;Database changed<br />
<br />
<strong>use 语句可以通告MySQL把db_name数据库作为默认&#xff08;当前&#xff09;数据库使用&#xff0c;用于后续语句。</strong>该数据库保持为默认数据库&#xff0c;直到语段的结尾&#xff0c;或者直到发布一个不同的USE语句&#xff1a;<br />
   mysql&gt; USE db1;<br />
   mysql&gt; <code>SELECT COUNT(*)</code> FROM mytable;   # selects from db1.mytable<br />
   mysql&gt; USE db2;<br />
   mysql&gt; <code>SELECT COUNT(*)</code> FROM mytable;   # selects from db2.mytable<br />
<br />
<strong>使用USE语句为一个特定的当前的数据库做标记&#xff0c;不会阻碍您访问其它数据库中的表。</strong>下面的例子可以从db1数据库访问作者表&#xff0c;并从db2数据库访问编辑表&#xff1a;<br />
   mysql&gt; USE db1;<br />
   mysql&gt; SELECT author_name,editor_name FROM author,db2.editor<br />
       -&gt;        WHERE author.editor_id &#61; db2.editor.editor_id;<br />
<br />
USE语句被设立出来&#xff0c;用于与Sybase相兼容。<br />
<br />
有些网友问到&#xff0c;连接以后怎么退出。其实&#xff0c;不用退出来&#xff0c;use 数据库后&#xff0c;使用show databases就能查询所有数据库&#xff0c;如果想跳到其他数据库&#xff0c;用<br />
   use 其他数据库名字<br />
就可以了。</div>
