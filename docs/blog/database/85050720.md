<p>【注】博主使用的是SQL Server2012 其他版本的安装类似。 <br /><span>【第一步】下载软件 </span><br />
链接&#xff1a;https://www.microsoft.com/zh-cn/download/details.aspx?id&#61;29066</p>

<p>32位的Windows 7操作系统&#xff0c;只需下载列表最下面的CHSx86SQLFULL_x86_CHS_Core.box、 <code>CHSx86SQLFULL_x86_CHS_Intall.exe</code>和CHSx86SQLFULL_x86_CHS_Lang.box三个安装包即可。64位同理。 </p>

<p><span>【第二步】安装软件 </span><br />
下载完成后&#xff0c;将下载的这三个安装包放在同一个目录下&#xff0c;并双击打开可执行文件<code>CHSx86SQLFULL_x86_CHS_Intall.exe</code>。系统解压缩之后打开另外一个安装文件夹SQLFULL_x86_CHS。打开该文件夹&#xff0c;并双击<code>SETUP.EXE</code>&#xff0c;开始安装SQL Server 2012。 </p>

<p>点击全新安装。 </p>
<p><img alt="è¿éåå¾çæè¿°" src="/images/blog/85050720/local-006.png" /></p>

【注2】当然也可使用免费版本。选择Evaluation即可。 </span><br />
许可条款。</p>
