<h2>1、TCP、UDP、HTTP与Soap协议</h2>
<h4><strong>TCP</strong></h4>
<p>面向连接的通信协议&#xff0c;通过三次握手建立连接&#xff0c;通讯完成时要拆除连接&#xff0c;由于TCP是面向连接的所以只能用于端到端的通讯。</p>
<ul>
<li>TCP提供的是一种可靠的数据流服务。</li>
<li>采用“带重传的肯定确认”技术来实现传输的可靠性。</li>
<li>TCP还采用一种称为“滑动窗口”的方式进行流量控制&#xff0c;所谓窗口实际表示接收能力&#xff0c;用以限制发送方的发送速度。</li>
</ul>
<h4><strong>UDP</strong></h4>
<p>面向无连接的通讯协议&#xff0c;UDP数据包括目的端口号和源端口号信息&#xff0c;由于通讯不需要连接&#xff0c;所以可以实现广播发送。</p>
<ul>
<li>UDP通讯时不需要接收方确认&#xff0c;属于不可靠的传输&#xff0c;可能会出现丢包现象&#xff0c;实际应用中要求程序员编程验证。</li>
</ul>
<h4><strong>HTTP</strong></h4>
<p>是一个通信协议&#xff0c;通过网络传输信息。</p>
<h4><strong>SOAP</strong></h4>
<p>是一个基于XML的协议交换消息&#xff0c;可以使用HTTP来传输这些信息。事实上HTTP是SOAP消息的最常见的传输工具。</p>
<h4><strong>关系</strong></h4>
<ol>
<li><strong>soap将信息进行XML的序列化后&#xff0c;再用http协议的方式再打包进行传送&#xff0c;传送的方式还是tcp或者udp</strong>。做个比喻就好理解了。tcp 和 udp 都是公路&#xff0c;暂且把tcp认为是一般公路&#xff0c;udp高速公路&#xff0c;soap和http就都是汽车&#xff0c;那么soap和http都可以在tcp和udp上跑。说soap可以通过http来传送&#xff0c;实际就是说soap是小轿车&#xff0c;http是装轿车的卡车&#xff0c;把soap的信息装到http里面&#xff0c;然后再运输&#xff0c;当然走的道路还是tcp或udp。说soap可以通过http协议来传输&#xff0c;这句话不太准确&#xff0c;比较准确第说法是&#xff1a;soap信息可以通过http协议包装后通过tcp或udp传输。</li>
<li>SOAP被描述为&#xff1a;简单的对象访问协议&#xff0c;简单对象访问协议&#xff08;SOAP&#xff09;<strong>是一种轻量的、简单的、基于 XML 的协议&#xff0c;它被设计成在 WEB 上交换结构化的和固化的信息。 </strong>SOAP 可以和现存的许多因特网协议和格式结合使用&#xff0c;包括超文本传输协议&#xff08; HTTP&#xff09;&#xff0c;简单邮件传输协议&#xff08;SMTP&#xff09;&#xff0c;多用途网际邮件扩充协议&#xff08;MIME&#xff09;。它还支持从消息系统到远程过程调用&#xff08;RPC&#xff09;等大量的应用程序。SOAP协议可以简单地理解为&#xff1a;SOAP&#61;RPC&#43;HTTP&#43;XML&#xff0c;<strong>即采用HTTP作为通信协议&#xff0c;RPC&#xff08;Remote Procedure Call Protocol  远程过程调用协议&#xff09;作为一致性的调用途径&#xff0c;XML作为数据传送的格式&#xff0c;从而允许服务提供者和服务客户经过防火墙在Internet上进行通信交互。</strong></li>
</ol>
<h4><strong>SOAP与HTTP的区别</strong></h4>
<ul>
<li><strong>都是底层的通信协议&#xff0c;请求包的格式不同&#xff0c;soap包是XML格式,http纯文本格式</strong></li>
<li>soap 的 可以传递结构化的 数据&#xff0c;http只能传输纯文本数据&#xff1b;</li>
<li>SOAP&#xff1a;简单对象访问协议             <strong>http是标准超文本传输协议</strong></li>
<li><strong>SOAP相对http&#xff08;<code>post/get</code>&#xff09;由于要进行xml解析&#xff0c;速度可能会有所降低。 </strong></li>
</ul>

<h4>3.4、<strong>HessianPHP</strong></h4>
<blockquote>

</blockquote>
