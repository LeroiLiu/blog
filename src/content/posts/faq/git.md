## 提交前发现改错文件怎么办

先确认错误改动是否已经提交。

如果还没有提交，可以只还原对应文件或手动编辑回正确状态。不要直接重置整个工作区，以免误删其他人的修改或自己未保存的工作。

如果已经提交，可以新增一个修复提交，或在确认不会影响协作的前提下整理提交历史。

## 合并冲突应该怎么处理

冲突处理的核心是理解双方修改意图，而不是机械保留一边。

建议步骤：

1. 先看冲突文件的业务含义。
2. 对比双方修改分别解决了什么问题。
3. 合并成同时满足需求的最终代码。
4. 运行相关检查。
5. 在提交信息中说明处理结果。

## 提交信息怎么写

提交信息应说明这次改动完成了什么，而不是描述你执行了哪些编辑动作。

示例：

```txt
docs: add GitHub Pages deployment guide
```
