1Panel 是 Linux 服务器运维管理面板，适合用图形界面管理网站、数据库、证书、容器、备份和常见应用。它很适合中小项目维护，但核心服务器安全仍然要自己把关。

## 安装前检查

建议在干净服务器上安装，并先确认：

- 系统版本在官方支持范围内。
- 有 root 或 sudo 权限。
- 服务器能访问安装脚本和镜像源。
- `80`、`443` 和面板端口没有冲突。
- 云服务器安全组允许访问面板端口。
- 生产服务器安装前先做快照或备份。

## 在线安装

官方 v2 在线安装命令：

```sh
bash -c "$(curl -sSL https://resource.1panel.pro/v2/quick_start.sh)"
```

如果国内访问较慢，可以打开官方中文安装页，按页面提供的镜像命令执行。

安装完成后记录：

- 面板地址。
- 面板端口。
- 安全入口。
- 用户名和初始密码。

如果忘记登录信息，可以 SSH 到服务器执行：

```sh
1pctl user-info
```

## 常用命令

```sh
1pctl help
1pctl status
1pctl restart all
1pctl user-info
1pctl update password
1pctl update port
1pctl reset entrance
```

如果命令和本机版本略有差异，以 `1pctl help` 输出为准。

## 建站流程

常见流程：

1. 域名解析到服务器。
2. 1Panel 中创建网站。
3. 绑定运行环境或反向代理。
4. 配置 SSL 证书。
5. 配置数据库、缓存、环境变量。
6. 上传代码或通过 Git 拉取代码。
7. 验证访问、日志、备份和监控。

部署 PHP 项目时注意：

- 入口目录通常是 `public`。
- PHP 版本和扩展要和项目一致。
- `.env` 不要提交到公开仓库。
- 上传、缓存、日志目录要有写权限。

部署 Go、Node、Java 服务时注意：

- 服务端口只需要本机监听时，优先绑定 `127.0.0.1`。
- 外部访问走网站反向代理。
- 应用本身要有进程托管或容器托管。
- 日志要能在面板或系统中追踪。

## 安全建议

- 面板端口不要使用太常见的端口。
- 保留安全入口，不要暴露简单路径。
- 开启复杂密码和必要的二次验证。
- 面板只允许可信 IP 访问时更安全。
- 数据库不要直接开放到公网。
- 备份要放到异地对象存储或另一台服务器。
- 定期更新面板、运行环境和系统安全补丁。

## 常见报错

| 问题 | 常见原因 | 处理方向 |
| --- | --- | --- |
| 面板打不开 | 端口未开放、服务未启动、安全入口错误 | `1pctl status`、安全组、防火墙、`1pctl user-info` |
| 忘记安全入口 | 安装信息丢失 | `1pctl user-info` 或 `1pctl reset entrance` |
| 应用安装失败 | Docker、镜像源、网络或磁盘问题 | 检查 Docker 状态、磁盘、应用日志 |
| 网站 502 | 容器或运行环境没有启动 | 看网站日志、容器日志、端口映射 |
| SSL 申请失败 | 域名未解析到服务器或 80 端口不通 | 检查 DNS、安全组、防火墙 |
| 备份失败 | 存储配置错误或磁盘不足 | 检查备份账号、桶权限、磁盘空间 |
| 数据库连接失败 | 账号、密码、主机、容器网络不对 | 先在服务器内连接测试 |
