# 关于解决TP5的public和<code>index.php</code>的掩藏解决方法

> **历史博客说明**
>
> 本文为 Leroi 的历史博客文章，原发布于 CSDN，现迁移并重新整理到本站。
>
> 原博客地址（CSDN）：[https://blog.csdn.net/Leroi_Liu/article/details/80958840](https://blog.csdn.net/Leroi_Liu/article/details/80958840)

之前也遇到过一些问题，解决了，但一段时间之后就会忘记，接下来，我将把解决方法与大家分享

首先，本解决方法是在（一键安装）lnmp环境下的修改，其他环境下的没有试过。这是值得注意的地方。

此方法适用于TP5，ThinkCMF5等

![](/images/blog/80958840/local-001.png)

首先，你需要指定根目录。

接着，你需要在lnmp1.4安装包里的tools文件夹下有一个`remove_open_basedir_restriction.sh`

执行：

![](/images/blog/80958840/local-002.png)

至此，问题得以解决

掩藏`index.php`需要重写：

~~~nginx
location / { // …..省略部分代码
if (!-e $request_filename) {
  rewrite  ^(.*)$  /index.php?s=/$1  last;
  break;
}
}
~~~

OK，问题至此圆满解决
