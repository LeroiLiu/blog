## 1、在一个空仓库中提交

~~~bash
echo "# ML">> README.md
git init
git add README.md
git commit -m "first commit"
git remote add origin xxxxxxxxxxxx
git push -u origin master
~~~

## 2、在一个已存在的仓库中提交

~~~bash
git remote add origin xxxxxxxxxx
git push -u origin master
~~~

## 4、创建分支并提交分支

~~~bash
git branch branch
git checkout branch
git add . git commit -m branch
git push origin branch
~~~
