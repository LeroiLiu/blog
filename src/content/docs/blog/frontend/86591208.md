### 所有示例以此 **wxml** 为基础

~~~html
<view class='boxs'>
  <view class='box'>
  </view>
  <view class='box'>
  </view>
  <view class='box'>
  </view>
</view>
.box{
width: 200rpx;
height: 200rpx;
background: greenyellow;
margin-right: 10rpx;
}
~~~

### 各位理解能力比较强的可以先理解一下这张图，就会对flex布局有更进一步的理解：

![弹性盒](/images/blog/86591208/local-001.png)

### 一、水平居中

#### 1、排列方向为水平方向

~~~javascript
.boxs {
  display: flex;
  align-items: center;
}
~~~

![](/images/blog/86591208/local-002.png)

#### 2、排列方向为竖直方向

~~~javascript
.boxs {
  display: flex;
  flex-direction: column;
  align-items: center;
}
~~~

![](/images/blog/86591208/local-003.png)

### 二、垂直居中

#### 1、排列方向为水平方向

~~~javascript
.boxs {
  display: flex;
  flex-direction:column;
  justify-content: center;
}
~~~

![](/images/blog/86591208/local-004.png)

#### 2、排列方向为竖直方向

~~~javascript
.boxs {
  display: flex;
  justify-content: center;
}
~~~

![](/images/blog/86591208/local-005.png)
